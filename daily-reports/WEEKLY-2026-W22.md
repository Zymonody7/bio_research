## 三、🔬 本周趋势分析

### 趋势 1：临床Agent范式的"行动论转向"——从静态问答到动态决策循环

本周B方向（临床Agent）产出8篇论文，数量和质量均为六个方向之首。跨越三天的论文形成了一条清晰的技术演化轨迹：

```
单轮推理 (传统 MedQA) 
  → 多轮诊断 (MedAction 5/25, MedExAgent 5/27) 
    → 闭环多专家推理 (RE-MCDF 5/27, MedLA 5/27) 
      → 动态证据检索+路由 (MedCoRAG 5/28)
```

MedAction 提出的"**thinking vs. acting 二分法**"是本趋势的理论锚点：现有医学训练数据教会模型从完整信息**推理**，但真正临床决策是在不确定中**行动**。这解释了为何医学LLM在benchmark上表现优异但临床部署效果有限。

**交叉机会**：将 MedAction 的多轮决策范式 + MedCoRAG 的动态专家调度 + 证据检索结合，构建"一边查知识库、一边开检查、一边更新诊断"的端到端临床Agent。对 renji_mngs 而言，可直接用于构建"mNGS阳性→主动检索文献证据→动态更新病原判定"的诊断闭环。

### 趋势 2：超越MLM——生物学特化的预训练目标正在涌现

传统蛋白质/基因组LM几乎全部基于MLM（掩码语言建模），本周出现了多种替代范式：

| 方法 | 核心思想 | 代表论文 |
|------|----------|----------|
| JEPA (联合嵌入预测) | 在latent space而非token space做预测 | ProteinJEPA |
| 离散扩散 (吸收态) | 以胚系序列为吸收态，消除记忆偏差 | Germline-Absorbing Diff. |
| 流匹配 (Flow Matching) | 潜空间条件流+无分类器引导 | CHASE |
| PU学习 | 建模"未被观察到≠不存在" | Evo-PU |

这些工作的共同点：**不是简单地把NLP的方法搬过来，而是从生物学第一性原理出发设计训练目标**。这标志着一个重要转折——生物序列的预训练范式正在从"NLP殖民"走向"生物学自主"。

### 趋势 3：基础模型的"生态有效性危机"——更大≠更好

本周多篇论文从不同角度揭示了当前生物学基础模型的根本性局限：

- **ViroBench (A1)**: NFM在属级OOD和时间漂移下性能崩溃，预训练数据的物种多样性远超参数规模的重要性
- **Evo2 3D探测 (E2)**: 7B参数、1M token上下文的DNA LM完全学不会3D染色质组织——需要根本性架构创新
- **What Makes a Representation Good (E1)**: 基因表达中扰动特异性信号稀疏，现有scFM未充分解决信号分离问题
- **Evo-PU (D1)**: 蛋白质序列存在固有的幸存者偏差，MLM学习的是有偏分布

**四篇论文的交集**：当前"更大模型+更多数据"的缩放路径可能已触及瓶颈。下一代基础模型需要：(1) 进化感知的训练目标；(2) 信号与噪声的显式分离机制；(3) 特定生态位（病毒 vs 细菌 vs 真核）的专用化策略。

### 趋势 4：隐私 × 可解释性的神经符号融合

ProtoMedAgent 是本周最优雅的方法设计。它的核心洞察：

```
传统 RAG:  图像 → LLM看图说话 → 报告     (容易检索谄媚)
ProtoMedAgent: 图像 → 原型网络锁定证据 → 隐私门控语义记忆 → Scribe-Critic反射 → 报告
```

"**先取证、后推理**"的范式天然抑制幻觉。结合 PACT 的层级安全策略和 STRAND 的机制可解释性，一个新兴的"可审计、可追溯、隐私保护"的临床AI范式正在成形。

**白空间**：将该范式推广到 mNGS 病原检测报告生成（"检出物种→检索证据→隐私保护→证据锁定的临床报告"），可能是 renji_mngs 的一个有区分度的技术特色。
