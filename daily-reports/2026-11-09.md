## 方向 A：mNGS + AI 病原检测

**A1 🔥 Large language models enable consensus-level interpretation in metagenomic diagnostics**
- 作者：Eike J. Steinig, Marcelina Krysiak, Kirti Deo 等 | medRxiv, 2026-07-31
- DOI: `10.64898/2026.07.29.26358751`
- 要点：把"专家判定"形式化为**结构化决策树 + LLM 推理**的混合分类器，用于无菌部位（脑脊液/眼液）短读长 mNGS 检测结果的临床相关性判读。本地部署的开源推理模型 Qwen3 在加入临床笔记后达到 97.2% 敏感度 / 100% 特异度（n=79，高于实验检出限），与专家共识相当；自动化判定还使参数基准测试与回归测试成为可能。
- 为什么收：**方向 A 与 B/C 的交点**——LLM 不做检测本身，而做"检测后判读"这一最依赖专家、最难规模化的环节，且强调本地部署与可回归测试，工程落地细节完整。

**A2 📎 Effects of a clinical metagenomics intervention on clinical outcomes... (DigiSep RCT)**
- 作者：Thorsten Brenner, Annabell Skarabis, Stefan J. Schaller 等 | Intensive Care Medicine, 2026-06-30
- DOI: `10.1007/s00134-026-08521-3`
- 要点：德国 24 个 ICU 的随机对照试验（mNGS 干预组 n=200 vs 对照 n=189）。主要终点 DOOR/RADAR 未显著改善（3.21 vs 3.49），但机械通气时间缩短（6.6 vs 9.3 天）等次要终点改善，未增加医疗成本。
- 为什么收：目前**最高质量的 mNGS 临床效用因果证据**（RCT 级），为"AI+mNGS"方向提供临床价值基线——若 AI 判读要证明价值，对照的就是这类终点设计。📎 方法学参照。

## 方向 B：Clinical Agent + RAG / Knowledge Graph

**B1 🔥 MedDP: A Graph-Based Large Language Disease Prediction Model**
- 作者：Ran Wang, Guilin Qi | Expert Systems, 2026-11-05
- DOI: `10.1111/exsy.70473`
- 要点：从 EHR 构建**患者特异性异构诊断图**（严格只用预测时刻之前的信息），GNN 编码检索候选疾病，再用 LLM 生成推理链并按"语义一致性 + 图一致性"打分；伪标签自训练缓解低资源。MIMIC-III F1 0.6724 / AUPRC 0.812，DDXPlus 平均 F1 0.81。
- 为什么收：KG 与 LLM 的结合点放在**证据可解释 + 时间防泄漏**上，是 GraphRAG 医疗方向少见的严谨设计。

**B2 🔥 EGIP: An Evidence-Grounded Interaction Protocol for Clinical Agents**
- 作者：Zecheng Ren, Ruichen Cong, Yi Min Chen | arXiv:2610.24539, 2026-10-17
- 要点：指出交互式临床 Agent 的评测被"环境暴露信息的方式"所混淆——最终准确率无法区分诊断推理能力与交互协议效应。EGIP 规定角色信息边界、只暴露可用动作不暴露结果、从存储的临床记录中检索检查结果，使不同决策策略在同一观测上可比。2 个 Agent 框架 × 5 数据集 × 6 模型，全部主对比提升；临床医生复核确认收益来自协议本身。
- 为什么收：**临床 Agent 评测方法论**的空白填补——类似 "prompt 泄漏" 的"协议泄漏"问题，值得在自建 Agent benchmark 时直接引用。

## 方向 C：RLHF 医学对齐

**C1 🔥 Hallucination Detection-Guided Preference Optimization for Clinical Summarization (HDSR / HDSR-PL)**
- 作者：Shamanth Kuthpadi Seethakantha 等 | arXiv:2605.28910, 2026-05-27
- 要点：推理时用幻觉检测器引导摘要迭代修订（HDSR，Llama-3.1-8B 幻觉 -24%），再把"检测器引导的修订轨迹"转成**偏好对**做微调（HDSR-PL，幻觉 -48%），MIMIC-IV-Note 真实临床文书，流畅度/相关性经人类专家与 LLM-Jury 双重验证不下降。
- 为什么收：给出了一条**"检测器 → 轨迹 → 偏好数据"的自动 DPO 数据管线**，绕开了医疗偏好数据稀缺问题。

**C2 🔥 When Medical Safety Alignment Fails: MedHarm Benchmark**
- 作者：Yige Li, Jun Sun, Wei Zhao | arXiv:2606.28332, 2026-05-26
- 要点：1,100 条高风险医疗查询、10 个安全关键类别（毒理、药理、隐蔽投毒、麻醉、胎儿伤害等），评估 15 个 LLM + 4 个护栏模型。核心发现：**表面对齐 ≠ 医疗安全**——已对齐模型仍给出可操作的危险回答，医疗微调反而可能加剧。
- 为什么收：直接攻击"alignment score 高 = 医疗安全"的假设，是 C 方向的负面结果型基准。

**C3 🔥 Evo-PI: Aligning Medical Reasoning via Evolving Principle-Guided Supervision**
- 作者：Xianda Zheng, Huan Gao, Meng-Fen Chiang 等 | arXiv:2606.31800, 2026-06-30
- 要点：反对静态监督（固定 prompt/规则/奖励模型），把**推理原则本身作为可生成、可评估、可演化的语言化监督信号**——原则引导模型、模型行为反哺原则，形成共演化闭环。在医学 VQA（8 个基准、多骨干）上一致提升。
- 为什么收：把"reward model 固定不变"这个 RLHF 默认假设打开，与 C 方向的 rubric 化趋势（InfiMed-ORBIT 等）衔接，且落在多模态医疗场景（跨界 C↔F）。

## 方向 D：Genomic Foundation Models

**D1 🔥 Learning Strand-Equivariant Tokenizations of DNA with MirrorDNA**
- 作者：Nirjhor Datta, Swakkhar Shatabda, Md. Shamsuzzoha Bayzid | bioRxiv, 2026-11-06
- DOI: `10.64898/2026.11.04.764207`
- 要点：**现有 DNA 语言模型在双链上不一致**：BPE/k-mer 分词器把 92–100% 的 TF motif 在两条链上切得不同，NT-v2、DNABERT-2、HyenaDNA 在反向互补输入下 25–31% 的预测会翻转。MirrorDNA 用保证镜像对称 token 边界的可学习分词器，对称性在全模型中可证明地保持；仅统计双链都判对的预测，MCC 超过 NT-v2/DNABERT-2/HyenaDNA 的两倍，参数量仅 2.3M。
- 为什么收：**D 方向今日最强发现**——把"基因组 FM 的数据增强问题"重构成"架构不变量问题"，评测协议（双链一致性计分）可直接复用。

**D2 🔥 MicrobeRT: A Framework and Suite of Fine-tuned Language Models for Genomic Sequences**
- 作者：Vijay Narayan, Brian B. Merritt, Sanjeevani Choudhery | bioRxiv, 2026-11-04
- DOI: `10.64898/2026.11.03.763945`
- 要点：在 Nucleotide Transformer、DNABERT、HyenaDNA 上微调，统一三个任务：物种级分类、耐药基因检测、致病性评估，目标是绕开"依赖可变参考数据库 + 高算力"的 shotgun metagenomics 采纳瓶颈。
- 为什么收：**D→A 的桥**：基因组 FM 直接用于病原检测读段，正是"foundation model 替代 reference database"这一叙事的具体样本（也呼应被排除的"数据库构建"方向的新解法）。

**D3 🔥 CellReg3D: Integrating DNA Large Language Models and 3D Genome Structure**
- 作者：Xiaoyu Wang, Yumeng Zhang, Sihan Chen 等 | bioRxiv, 2026-11-04
- DOI: `10.64898/2026.11.01.763421`
- 要点：多尺度多模态框架——DNA LLM 编码局部序列 + Hi-C 派生的 3D 染色质互作捕捉长程调控，解决纯序列模型无法建模长程基因组互作的问题，达到 SOTA。
- 为什么收：序列基础模型的**"上下文补全"路线**（加 3D 结构而非加大参数），与近期 DNA FM 长上下文路线形成对照。

## 方向 F：Multimodal Clinical Agent

**F1 🔥 SMILE: A Structured Multi-Agent Clinical Reasoning for Liver Ultrasound Understanding**
- 作者：Haris Ghafoor, Minjee Seo, Seonaeng Cho 等 | arXiv:2611.02581, 2026-11-02
- 要点：针对肝脏超声报告生成——三个专家 Agent（图像形态学解读、临床分期推理、定向 VQA）+ **裁判引导的共识机制**聚合，克服单一 VLM 推理通路在细微视觉证据、异质病态、配对监督不足下的局限。
- 为什么收：多智能体 + judge consensus 的结构化推理在超声这一低对比度模态上的落地，架构可迁移。

**F2 🔥 ERIA: An Instruction-Optimized Agent for Clinical EEG Reporting**
- 作者：Ahmed Sameh, Gayal Kuruppu, Neeraj Wagh 等 | arXiv:2611.01394, 2026-11-01
- 要点：单个 27B 控制器编排专用参数化工具与信号处理工具（背景异常、睡眠觉醒、癫痫样放电、频谱/蒙太奇/信号质量确定性分析）分析全时程 EEG；**不微调权重、不做多 Agent 编排，只用 GEPA（遗传-帕累托）优化自然语言分析策略**，以专家报告为反馈；医生对齐的报告质量提升且迁移到外部 EEG 基准。
- 为什么收：**"优化 prompt 策略而非训练模型"**的对齐新范式（C↔F 跨界），且是本地可部署的全记录级报告 Agent。

**F3 🔥 A clinician aligned vision language framework for stepwise interpretation in fundus fluorescein angiography (Clin-FFA-VLM)**
- 作者：Zichang Su, Xiaocong Liu, Bingtao Guan 等 | npj Digital Medicine, 2026-07-12
- DOI: `10.1038/s41746-026-02932-8`
- 要点：模仿视网膜专家认知流程分三阶段（病灶感知 → 报告生成 → 诊断决策），13,178 张 FFA 训练；病灶检测 F1 0.834、报告实体级 F1 0.73、联合诊断 F1 0.77，外部两家医院验证 F1 0.78/0.70；**200 例前瞻性阅读者研究中显著提升医学生与住院医师准确率（p<0.05）**。
- 为什么收：罕见的"AI 提升人类而非替代人类"的前瞻性证据（journal 级、npj），stepwise 对齐思路可迁移到其他影像模态。

**X2 🔥 From Tool State to Scientific Action: Auditing Decision Provenance in Biomedical Research Agents (BioAgent-DF)**
- 作者：Xingyu Yi, Xinya Zhang, Yunshen Zhou 等 | arXiv:2611.01527, 2026-11-01
- 要点：同一个结论可能读了/引了不同证据。用"在同一计算位点保存的参考值 vs 移植值"做恢复/替换实验，跨 8 个 SciFact 批次发现 Qwen3.5-4B 有 3 组、Gemma 3 4B IT 有 4 组可复现的引用/读取变化；**完整恢复证据集时结论却不变**，说明审计必须同时追踪证据与最终答案；在 hERG 心脏安全实验分配中，静默数值故障改变了测试决策而结论未变。
- 为什么收：**生物医学 Agent 的"证据溯源审计"**新议题——Agent 安全从 prompt 层下沉到工具状态层。

## 🧠 前沿洞察与头脑风暴

**一、跨方向信号：三条正在合流的线。** 其一，"判读层替代检测层"——A1（LLM 接管 mNGS 专家判读）与 D2（MicrobeRT 用基因组 FM 直接分类读段）指向同一命题：当参考数据库与专家判定都成为瓶颈时，基础模型成为新的"解释层"。其二，"对齐从训练时移到推理时"——C3（Evo-PI 演化原则）、F2（GEPA 只优化自然语言策略、权重冻结）、C1（检测器引导的推理时修订再转偏好对）共同表明：医疗场景下昂贵且脆弱的 RLHF 正被"可编辑的监督文本"替代，reward model 固定不变的默认假设正在松动。其三，"Agent 安全下沉到状态层"——B2（交互协议泄漏污染评测）、X2（工具状态与证据溯源审计）、C2（MedHarm：对齐分高≠医疗安全）显示，安全与评测的重心从输出措辞转向信息流与证据链。

**二、空白点（white spaces）。** (1) **双链一致性之外的基因组 FM 不变量**：MirrorDNA 只解决了 strand 对称，坐标系、阅读框、密码子相位等对称性尚未系统审计——可做一个"基因组 FM 不变量清单 + 基准"。(2) **mNGS 判读的前瞻性终点**：A1 是回顾性验证，A2 的 RCT 又没测 AI 判读——"AI 判读 mNGS 的 DOOR/RADAR 型 RCT"完全无人做，这是能上高分期刊的题目。(3) **临床 Agent 的协议标准化**：EGIP 证明协议会混淆评测，但尚无 FHIR 之于交互协议的通用规范。(4) **证据溯源的因果审计**：X2 的"恢复证据、结论不变"现象可推广为 Agent 因果审计框架，与可解释性社区对接。(5) **原则演化的漂移监控**：Evo-PI 让原则自演化，谁来防止原则漂移到不安全区域？这是 C 方向下一步的必然问题。
