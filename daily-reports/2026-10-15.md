## 方向 A:mNGS + AI 病原检测

### 🔥 A1. Basecalling-free resistance gene identification using a hybrid transformer in raw nanopore signals (NanoResFormer)
- **期刊**:Frontiers in Microbiology(2026)| **DOI**:10.3389/fmicb.2026.1748934 | PMID:41788336
- **作者**:Jakubicek R, Vorochta J, Jakubickova M 等
- **核心**:混合卷积-Transformer 模型直接在**原始 nanopore 电流信号**上检测并定位抗生素耐药基因(ARG),**完全跳过 basecalling** 这一算力瓶颈;floating-window 策略处理变长输入。
- **关键数字**:灵敏度 92.6%,精确率 >93%,低延迟,可在测序进行中实时输出 resistome profile。
- **为什么收**:多数"raw signal"工作只做 read 级分类,这篇做到了**基因级检测与定位**;把"实时性"从管线优化变成架构选择,是方向 A 少见的范式层创新。

### 🔥 A2. AMR-GNN: a multi-representation graph neural network framework to enable genomic antimicrobial resistance prediction
- **期刊**:Nature Communications(2026-03-06)| **DOI**:10.1038/s41467-026-69934-8 | PMID:41792137
- **作者**:Nguyen HA, Peleg AY, Wisniewski JA 等
- **核心**:用 GNN 整合**多种基因组表征**做 AMR 表型预测,正面处理 ML 在病原基因组上的老大难——**克隆关系导致的性能虚高**,并用图结构挖掘可解释生物标志物。
- **关键点**:先在铜绿假单胞菌验证,再在最大公开数据集(涵盖革兰氏阴性/阳性菌)上证明跨物种泛化性。
- **为什么收**:"多表征 + 克隆去偏 + 可解释"三件事在同框架内解决,可作为基因组 AMR 预测的干净基线。

## 🧠 前沿洞察与头脑风暴

**交叉信号 1:从"能不能预测"到"有没有机制理解 / 物种适配"。** 今日 D 方向的 Porcine MutBERT 提出了一个尖锐论断:猪基因组的调控特征由驯化与人工选择塑造,用人类或模式生物数据训练的通用 gLM **系统性地捕捉不到**。这与你此前追踪的《Genomic LMs Fail Positional Regulatory Logic》《In Search of Lost DNA Sequence Pretraining》构成同一条批判线索——通用 gLM 的失效不只是"规模不够",而是**训练分布与目标分布的生物学错配**。由此推出的白空是:**面向特定物种/群体的轻量 gLM + 靶向 masking 策略**(而非继续堆参数),可能是比"更大预训练"更有产出的路线。建议把"物种特异 / 群体特异 gLM"设为 D 方向的常设子标签。

**交叉信号 2:统计保证开始进入临床多模态 agent。** TrustEndo 把 conformal prediction 扩展到 MLLM 输出,给出 95% 覆盖率保证并把幻觉率从 15–20% 压到 7.8%。此前你收的 ProtoMedAgent、CuraView 多从"检测幻觉"入手,而 TrustEndo 走的是"给输出配可校准的置信语义"。**"可证明的可靠性"替代"经验性的低幻觉率"可能成为临床 agent 的下一个硬指标**,尤其在监管审批语境下。进一步的空白:保形预测依赖可交换性假设,而临床数据分布随时间/科室漂移,**conformal 保证在分布漂移下如何失效、如何自适应重校准**,目前几乎无人在 MLLM 场景下研究。

**交叉信号 3:对齐的"显式通过、隐式残留"。** C2(PLOS ONE)发现 LLM 可以通过显式社会偏见测试却仍保留隐式偏见,并在六个高风险类别上量化其对临床决策与健康公平的影响。这提示一个评测方法论转向:**偏见/安全评测必须从"离散问答测试"升级为"行为层面的潜在关联测量"**。它与你已收的 TRAIAL+ERR(伦理推理 vs 安全对齐)、Deception in clinical LLMs 共同指向:**当前的医疗对齐评测存在系统性盲区,模型的"表面合规"与"深层倾向"可以脱节**。

**白空 1:agent 化的增量价值测量。** B3(慢性胃炎)做了裸 LLM vs AI agent 的对照,但这类"agent 到底比直接用 LLM 好多少"的严格量化研究极少——绝大多数 agent 论文只报告绝对性能,不设 LLM-only 基线。**这导致整个 clinical agent 方向的增益主张缺乏证据基础**,值得作为方法论白空专门追踪,并在你自己的实验设计中强制加入该对照。

**白空 2:agent 可信度从临床外溢到生信科研。** THREAD-Bio 指出 11 个同行评审 agentic 生信系统无一把"问题→样本→决策→计算→证据→结论"连成可追溯链,并区分继承错误 / 自主放大的错误 / 涌现性失败。这与 B 方向的部署后行为审计、X 方向的审计日志 LLM 建模是同一母题:**当 agent 接管决策,provenance 与行为建模就成为新的研究对象**,而不只是工程细节。

**搜索策略建议:** ① **方向 A** 本轮 PubMed 命中多为综述与临床应用,mNGS+AI 的架构层创新稀少,建议下轮把 query 转向 "raw signal / basecalling-free / streaming / real-time / in-situ sequencing" 等技术关键词而非 mNGS 缩写——本轮 A1 即是靠 "nanopore + raw signal" 捞出的;② **方向 C** 建议把 RLVR / GRPO / process reward 作为常设检索词(本轮 Med-R1 即由 GRPO 线索捞出),并把 arXiv 作为该方向的 PRIMARY 源,因为 RL-医疗推理的最新工作发表在期刊前普遍有 arXiv 版;③ **方向 D** 建议新增两个子标签:**"genomic FM safety/biosecurity"** 与 **"species/population-specific gLM"**——前者你已在 2026-10-10 覆盖,后者今日由 Porcine MutBERT 开出,且与已有 D 方向论文形成连续谱系。
