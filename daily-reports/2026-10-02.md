## Direction C — RLHF / 医学对齐（3 篇）

### C1. 🔥🔥 DPO-Clin: Linguistically-Aligned and Visually-Grounded Preference Optimization for Clinically-Augmented Medical Report Generation
- **来源**：arXiv: [2608.08494](https://arxiv.org/abs/2608.08494)（ECCV 2026 接收）| 2026-08-09
- **作者**：Hu Q, Luo Y, Guo Y, Wang H, Wang Q, Li Q, Wang Z
- **要点**：医学报告生成（MRG）中朴素 DPO 把"临床发现"与"语言风格"纠缠在一起。DPO-Clin 三件套：① ECD 实体级临床诊断模块，精准剥离语言差异只保留临床差异构造偏好对；② M2DPO 检索增强多模态 DPO，用视觉上下文切换强制文本偏好反转；③ 对"正确但高不确定"实体做反事实修改构造靶向偏好数据。在 MIMIC-CXR、IU X-Ray 与内镜私有数据集上显著优于 SFT 与既有 DPO 方法。
- **为何收录**：**今日最佳**。把医学对齐的数据粒度从"整篇报告"推进到"临床实体级"，同时给出多模态 grounding 的偏好优化配方——方向 C 与 F 的交叉信号。

### C2. 🔥 Analyzing and Improving Fine-grained Preference Optimization in Medical LVLMs
- **来源**：arXiv: [2606.12590](https://arxiv.org/abs/2606.12590) | 2026-06-10
- **作者**：Mohammadizadehsamakosh S, Sarkar P, Sigal L, Etemad A, Dolatabadi E（York / UBC / Vector Institute / Queen's）
- **要点**：指出医学 LVLM 偏好对齐三大缺陷：序列级奖励把临床关键 token 与填充词等同、以 SFT 参考作偏好对带来 off-policy 分布漂移（奖励黑客走"风格捷径"）、缺乏显式视觉 grounding。方案：双向 token 级 KL 正则 + 视觉对比 grounding（干净图 vs 病灶扰动图），并以最小编辑 on-policy 构造偏好对（只改临床错误 span、保留语言风格）。
- **为何收录**：与 C1 互为印证——"细粒度 + on-policy + 视觉接地"正在成为医学偏好优化的标准组件。

### C3. 🔥 Clinical-R1: Clinical Objective Relative Policy Optimization（CRPO）
- **来源**：arXiv: [2512.00601](https://arxiv.org/abs/2512.00601) | 2025-12
- **作者**：Gu B, Zhou H, Segal B, Liu F, Wu J, Cao Z, Zhong H, Clifton L, Clifton D（Imperial / Oxford / UCL / Cambridge）
- **要点**：GRPO 只奖励正确性，与医学的多维目标（忠实、全面）错位。CRPO 用规则化、可验证的奖励信号同时优化 accuracy / faithfulness / comprehensiveness，无需人工标注；训练出的 Clinical-R1-3B 在三个基准上忠实度与完整性显著优于标准 GRPO。
- **为何收录**：可验证 RL（RLVR）进入医疗对齐的代表作——奖励设计从"答对"走向"临床推理质量三维评分"，与 DPO 系列形成互补路线。

## 🧠 前沿洞察与头脑风暴

**本周最强交叉信号：医学对齐的"粒度革命"。** C1（DPO-Clin）与 C2（Fine-grained PO）不约而同指出同一问题：把整篇报告/整段回复作为偏好对的基本单位，会让临床关键信号被语言风格淹没——前者用实体级诊断模块剥离风格，后者用 token 级 KL + 最小编辑构造 on-policy 偏好对。而 C3（Clinical-R1/CRPO）从奖励侧给出答案：可验证的多维规则奖励（正确+忠实+全面）绕开人工偏好标注。可以预见，2026 下半年医学对齐的主流配方将是「实体/token 级偏好数据 × 可验证规则奖励 × 视觉 grounding 约束」三者的组合，单纯的成对偏好数据会迅速过时。

**基因组基础模型的"审计年"。** D2 对 SegmentNT 的长度/位置偏差审计与既往"genomic LM 失败于位置调控逻辑"的发现同流——模型分数上涨但内在系统性偏差未消。这提示：对 genomic FM 的下游使用应默认加入位置/长度的敏感性分析，类似 NLP 的"bias checklist"。同时 D3 把深度上下文建模注入 ULP-WGS cfDNA 癌检，D1 把 FM 推向植物基因"创造"——genomic FM 正在从 benchmark 走向两个真实场景：低成本临床检测与合成生物学设计。

**临床 agent 的"执行化"。** B3（自主放疗计划编排）与 F3（虚拟 MDT 多智能体）显示 agent 正从"回答问题"走向"完成临床工作流"：前者接入 TPS 闭环执行，后者模拟科室协作分工。白空间在于：**带审计日志的执行型临床 agent 评测基准**——现有 benchmark（MedQA 等）测的是知识，不是工作流完成质量；AgentRx 类工作刚起步，但缺少对"执行安全"（计划变更可追溯、错误可回滚）的度量。
