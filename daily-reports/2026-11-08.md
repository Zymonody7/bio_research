   - **F 方向的形态学范本：多模态个人健康 agent 的难点不在模型，而在于'用户旅程→子智能体分工→可测基准'的完整工程链路——1350 小时人工评测本身就是门槛。**
2. **[B] A multimodal tool-augmented agent for evidence-based clinical decision support in longitudinal AMD follow-up.**（*NPJ Digital Medicine*, 2026-11-03, DOI `10.1038/s41746-026-03412-9`）—— **AMDagent**
   - 针对 AMD 纵向随访中"人工综合多模态视网膜影像耗时且易漏信息"的痛点：**定量影像分析工具 + 指南检索**双轮驱动，把纵向影像发现链接到可执行的管理建议，生成结构化、面向临床医生的决策支持输出，**全程保留可追溯的证据来源**（解决 LLM 摘要缺乏定量锚定与证据归属、难以审计的问题）。
   - **B 方向信号：临床 agent 的竞争点已从'回答对不对'转向'证据链能不能审计'——工具调用（定量影像）+ 检索（指南）+ 可溯源输出，是 npj Digital Medicine 级别的验收模板。**
3. **[D] Genomic language models decode bidirectional promoter activity and reveal conserved regulatory patterns across plant species.**（*Nature Communications*, 2026-11-05, DOI `10.1038/s41467-026-79328-5`）
   - 双向启动子（BDP）传统上靠基因间距离阈值识别、无法从序列推断活性。作者用基因组语言模型 **Evo2** 预测 BDP 活性：**Evo2 embedding 全面超越 k-mer、TFBS 矩阵与序列 CNN 基线**；在拟南芥、玉米、水稻、小麦四物种上训练的模型**可迁移到留出物种**；**在 *Spartina alterniflora* 中做 in planta 验证**确认预测的高活性 BDP；并用**稀疏自编码器（SAE）**解读出跨物种保守的调控语法。
   - **方向 D 信号：'预训练底座 + 冻结读出（SAE）+ 湿实验闭环'正在成为基因组 FM 的标准三件套——可解释性从归因图升级为可验证的调控规律。**

## A. mNGS + AI 病原检测

**1. 🔥 Predicting clinically actionable metagenomic next-generation sequencing in sepsis through dynamic inflammatory trajectories.**（*Frontiers in Microbiology*, 2026, DOI `10.3389/fmicb.2026.1949602`, PMID 42978829）
- Ding X, Bao P, Huang X, Xu R
- 单中心回顾性 **109 例脓毒症 mNGS** 队列（72 例进入建模）：核心问题不是"检出什么"，而是**"mNGS 报告会不会真正改变抗菌用药"**。加入 **mNGS 报告前后白细胞变化（dWBC）**后，表观 AUC **0.744 → 0.816**，bootstrap 校正后 **0.697 → 0.768**，Brier **0.228 → 0.207**；dWBC 校正 OR 1.14（95%CI 1.02–1.28, P=0.025）。可操作组 mNGS 阳性率 94.8% vs 非可操作组 84.3%，检出谱比培养更广。
- **A 方向信号：mNGS 的价值瓶颈已从'检出'移到'可操作性预测'——宿主反应时序信号（而非病原信号）才是决定用药改变的判别层，这正是 mNGS×AI 决策 agent 的输入结构。**

**2. 🔥 Machine Learning based Classification of Ocular Pathogens using Host-transcriptomic Signatures: a proof-of-concept.**（*Research Square* 预印本, 2026, DOI `10.21203/rs.3.rs-11233042/v1`, PMID 42990524）
- Plumber MT, Kumar R, Yadavalli T
- 330 份人 RNA-seq（177 感染 / 153 对照）、6 种病原（HSV-1、CMV、曲霉、念珠菌、铜绿、结核）、36 个 BioProject/24 种宿主细胞，Random Forest 分类。**关键的方法学诚实性**：随机 CV 平衡准确率 0.85–0.92，但在**按研究分组的留一验证（消除跨研究信息泄漏）下降到 0.519–0.60**（峰值 0.70，7 类随机水平=0.14）；UMAP 显示按病原/界（病毒/真菌/细菌）清晰聚类，跨界分离度大于界内。
- **A 方向信号：'宿主转录组替代病原直接检测'是 mNGS 之外的第二条病原判别路线——而它给出的最值钱结论是泄漏校正后性能腰斩：任何病原 AI 的评测都必须按数据来源分组验证。**

> 💡 **A 方向观察**：与 11-06/11-07 连续一致——**"mNGS 序列判读 agent / 病原 LLM"直接命中仍为零**（arXiv 兜底检索仅命中 2022 年前旧文与已收录的 METAGENE-1）。本轮 A 方向两篇新作的共同点是**绕开病原序列本身，改用宿主侧动态信号**。white space 未被填补，反而更清晰了。

## C. RLHF Medical Alignment

**5. 🔥🔥 Improving clinical reliability of LLM reasoning for depression assessment via structured generation and GRPO.**（*Science Progress*, 2026, DOI `10.1177/00368504261467483`, PMID 42496710）
- Bao E, Perez A, Parapar J
- 在 **ReDSM5**（1,484 条 Reddit 帖、执照心理学家标注 DSM-5 症状+专家理由）上微调 1B–27B 模型，比较 SFT vs **GRPO**，奖励 = **症状分类准确率 + 生成理由与临床理由的质量复合**。结果：GRPO 一致优于 SFT，**中等规模模型相对增益 >10%、加权 F1 >0.60**；生成结构化 DSM-5 理由再带来 **+0.09–0.39 F1**（复杂语境症状增益最大）；定性分析显示 GRPO 促使模型**引用症状相关证据而非表面线索**。
- **C 方向信号：'对齐'与'可解释'被同一个复合奖励同时拿下——GRPO 在医疗场景的真正卖点不是刷分，而是让 RL 训练出的解释天然贴合临床推理结构。**

**6. 🔥 Cross-paradigm audit of large language model judges for clinical text evaluation.**（*NPJ Digital Medicine*, 2026, DOI `10.1038/s41746-026-03443-2`, PMID 42982942）
- Pakull TMG, Warmer S, Arzideh K, Hilser T et al.
- **6 个开源权重模型 vs 专家评委**、**4 个德语临床数据集**（报告/护理文书摘要、出院小结、患者信）、3 种范式 × 4 种提示配置：**没有任何配置跨范式可靠**；所有 judge 都有位置偏差与身份偏差；**用 LLM-judge 替代专家面板：57.2% 的逐点评分类别改变、41.7% 的成对胜负翻转、漏掉 10.2% 的临床错误、并因高估"简洁/准确"而颠倒临床优先级**。
- **C 方向信号：奖励模型/judge 的临床校准是 RLHF 管线最薄弱的一环——评测基建本身需要审计，'用 LLM 监督 LLM'在临床域尚不安全。**

**7. 🔥 A S.C.O.R.E. framework for evaluating open-ended responses from large language models in healthcare.**（*Cell Reports Medicine*, 2026, DOI `10.1016/j.xcrm.2026.102883`, PMID 42349414）
- Tan TF, Elangovan K, Ong J, Ke Y, Lee A
- 提出 **S.C.O.R.E.**（Safety、Consensus & Context、Objectivity、Reproducibility、Explainability）五维结构化专家评审框架，在 GPT-4o / Claude 4 Sonnet / DeepSeek 上、跨眼科/用药/麻醉三域验证：**BLEU/ROUGE/BERTScore 频繁把临床恰当的回答误判为错误**；S.C.O.R.E. 内部一致性 Cronbach's α=0.745，效应量 Cliff's δ=0.68–0.92 能识别优化状态；**模型排名跨专科反转**（GPT-4o 仅在被优化的眼科领先）——证明领域特化既是必要的、也可被专家评审检测出来；可输出标准化文档支撑合规。
- **C 方向信号：自动指标与专家评审在医疗域正式'脱钩'——这为偏好数据与奖励模型提供了可复用的临床验收协议。**

## 🧠 前沿洞察与头脑风暴

**1. "谁来当裁判"成为医疗 AI 的主战场。** 本轮 C 方向三篇构成一组完整证据链：LLM-as-judge 在德语临床文本上**漏掉 10.2% 的临床错误、翻转 41.7% 的胜负**（npj Digit Med）；S.C.O.R.E. 显示 **BLEU/ROUGE/BERTScore 系统性误判临床恰当回答**（Cell Rep Med）；而 GRPO 用**复合奖励（分类准确率+理由质量）**同时提升准确率与可解释性。三者合起来指向：**RLHF 医疗对齐的瓶颈已从"有没有偏好数据"转为"奖励/评委信号本身有没有临床效度"**。建议 C 方向补搜 `reward model validation clinical`、`LLM-as-judge bias healthcare`、`expert panel vs automatic metric`。

**2. 宿主信号正在取代病原信号，成为 A 方向的实际判别层。** 本轮两篇 A 共享同一结构：mNGS 的价值瓶颈是**可操作性预测**（dWBC 时序 → AUC +0.07），病原直接检测太稀薄时改用**宿主转录组**（6 病原分类，泄漏校正后仍 0.519–0.60 ≫ 随机 0.14）。而"mNGS 序列判读 agent"连续三日命中为零。**空白机会：把宿主反应时序 + mNGS 检出 + agent 决策闭环做成一个系统**——检索可用 `host response trajectory AND metagenomic AND agent`。

**3. 基因组 FM 进入"冻结底座、可证伪读出"阶段。** Evo2+SAE 解码双向启动子并做 in planta 验证（Nat Commun）、DeepAllele 用**配对等位输入**自带差分对照（Genome Res）、甜瓜工作**零微调**只训探针（Genes）——加上 11-07 的 Chiron3D 可解释头，四篇共同确认：**D 方向的复用范式 = 冻结预训练底座 + 探针/SAE/归因读出 + 湿实验或跨物种验证**。建议检索 `frozen genomic model probe`、`sparse autoencoder genomic language model`、`paired allele input model`。

**4. Agent 科学的对象从"个体"移到"交互"。** Nature Communications 的立场文章提出交互架构框架，正好接住 11-07 的"Hard to Halt（错误由交互层引入、非推理层）"与本轮 HM-CDSS 的分层动作空间。**临床 agent 缺一套组合基准：既有 abstention/叫停维度，又有交互层审计（谁传递了什么、在哪一层失真）**——这可能是 B/F 方向下一个可发论文的切口。

**5. 检索与去重策略建议。** ① 本轮 **4/15 高价值论文（npj Digit Med、Cognitive Computation、Nat Commun×2）PubMed 尚未索引，全部由 OpenAlex 召回**——OpenAlex 应从"secondary"升为与 PubMed 并列的必跑步骤；② 语料级去重再次拦截 2/21（9.5%），**"DOI 键 + 历史日报全文"双轨必须固化为前置步骤**；③ 方向 A 的 arXiv 兜底只召回 2022 年前旧文，说明 mNGS×agent 的空白是真实空白，不是检索盲区。

**本周一句话：** 医疗 AI 从"造更强的模型"转向"重建可审计的裁判体系"，基因组 FM 从"更大预训练"转向"冻结底座+可证伪读出"——两条线的交点（**带临床效度奖励信号、且能被交互层审计的多模态 agent**）目前几乎无人占位。
