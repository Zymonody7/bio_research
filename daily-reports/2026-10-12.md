## 方向 B：Clinical Agent + RAG / 知识图谱（4 篇）

**B1.** 🔥 *Computable longitudinal patient journeys from structured and unstructured EHR data*
- 期刊：Nature Medicine（2026-09-10）｜PMID: 42742184
- 摘要要点：大部分 EHR 数据存在于非结构化文本（症状叙述、不良反应、治疗决策依据、依从性、家族史），而结构化编码字段仅部分反映。本文提出从结构化+非结构化 EHR 构建可计算纵向患者旅程的方法。
- **关注理由**：顶刊（Nature Medicine），直击临床 Agent 的底层数据瓶颈——把非结构化病历转成可计算时间线，是 Clinical Agent + RAG 的关键前置能力。

**B2.** 🔥 *EHR-RobustGym: Benchmarking and Training Agents for Robust Clinical Reasoning*
- arXiv: `2609.39371`（2026-09）
- 摘要要点：真实医院工作流中 EHR 噪声大、常缺少证实某事件/测量所需的证据。即使检索成功，临床 Agent 也会忽略证据缺口而返回"看似合理但无支撑"的答案。提出 EHR-RobustGym——可扩展交互式环境，用于评测与训练鲁棒临床推理 Agent。
- **关注理由**：针对临床 Agent 的"证据缺失鲁棒性"这一关键痛点，提出专门训练/评测环境，与我方 Clinical Agent 研究直接相关。

**B3.** 📎 *A large language model-enhanced knowledge graph framework for text-implied public health policy gap screening*
- 期刊：Frontiers in Public Health（2026-09-07）｜DOI: `10.3389/fpubh.2026.1937335`
- 摘要要点：针对政策文本中"文本隐含的结构性缺口"筛查，现有文本分类器/LLM 提示/检索方法多停留在文档级。本文提出 LLM 增强的知识图谱框架，聚焦数字健康可执行性、行为可及性、服务支持覆盖等维度。
- **关注理由**：LLM+知识图谱做结构化缺口推理的方法学，可迁移至临床知识图谱推理（方法参考）。

**B4.** 📎 *GlyRAG: Context-Aware Retrieval-Augmented Framework for Blood Glucose Forecasting*
- 期刊：IEEE JBHI（2026）｜DOI: `10.1109/JBHI.2026.3737468`｜PMID: 42804391
- 摘要要点：基于 CGM 数据的血糖预测可支撑血糖异常风险预警，但现有神经网络把 CGM 当纯数值序列，忽略信号形态中的上下文信息。GlyRAG 将 LLM 引入时间序列预测，做上下文感知的检索增强预测。
- **关注理由**：RAG 从文本迁移到临床时间序列（CGM）的创新用法，方法参考。

- bioRxiv（2026-10-01）｜DOI: `10.64898/2026.10.01.756029`
- 摘要要点：基因组基础模型（GFM）有望直接从 DNA 序列推断变异的调控后果，但其临床可用性尚不清晰。本文在**零疾病特异性微调**下，于三个递增难度设定中评测 AlphaGenome 对 ALS 遗传学的理解能力，系统揭示其局限。
- **关注理由**：直击"GFM 能否转化到临床"的核心问题，是评估类代表作，与我方关注的 GFM 泛化/局限完全一致。

**D2.** 🔥🔥 *Probing Genomic Foundation Models with Splice-Variant Perturbations*
- bioRxiv（2026-10-02）｜DOI: `10.64898/2026.10.02.756289`
- 摘要要点：随着基准饱和，传统验证无法捕捉 GFM 的概率化表示。本研究以机制为中心，用专家精修的单核苷酸替换（剪接区）扰动，探测自监督通用模型（NTv3 650M、Evo2 40B、Genos 10B）与任务专用模型（SpliceAI、AlphaGenome、Borzoi）。
- **关注理由**：提出"机制化扰动探针"来替代饱和基准，是 GFM 评测方法学的范式创新，非常值得借鉴。

**D3.** 🔥 *Cerberus: bidirectional state space blocks improve accuracy and efficiency of regulatory sequence models*
- bioRxiv（2026-10-02）｜DOI: `10.64898/2026.10.02.756377`
- 摘要要点：序列→功能模型（如 Borzoi 用自注意力计算长程互作）受限于参考基因组可用训练序列的上限——新 assay 增加的是标签而非序列，因此需要在有限序列多样性下学得更好的架构。Cerberus 用双向 state space block（SSM）替代长程注意力，兼顾精度与效率。
- **关注理由**：架构层面的 GFM 创新（SSM 替代 attention），针对"训练序列受限"这一真实瓶颈，工程价值高。

**D4.** 🔥 *Fine-tuning genomic models on rare splicing events identifies a novel biomarker of TDP-43 pathology*
- bioRxiv（2026-10-07）｜DOI: `10.64898/2026.10.07.757366`
- 摘要要点：GFM 预训练于大规模基因组数据，但其微调后预测罕见疾病相关事件的能力尚不清楚。以 TDP-43 cryptic exons（神经退行性疾病相关、标准注释覆盖差的剪接事件）为测试对象，对比 AlphaGenome 与 OpenSplice 等，发现新的 TDP-43 病理生物标志物。
- **关注理由**：把 GFM 微调落到"罕见疾病生物标志物发现"，是从预训练到临床转化的具体闭环案例。

## 🧠 前沿洞察与头脑风暴

**跨信号一：GFM 正从"刷榜"转向"机制化探针 + 临床转化压力测试"。** 本日 D 方向 4 篇高度同频：AlphaGenome/Evo2/NTv3 等通用模型在剪接、调控、ALS 等疾病场景被系统"审讯"。共同信号是——随着预测基准饱和，社区意识到 leaderboard 高分≠临床可用。Probing GFM 用"专家精修单核苷酸扰动"作为机制化探针，Limitations-of-GFM 用"零微调三难度递增"做转化压力测试。这提示一个明确的 white space：**缺乏一个统一的、以"临床可解释 + 机制正确"为轴的 GFM 评测协议**。若能把"扰动探针 + 疾病零样本 + 置信度校准"整合成标准 harness，将是高价值贡献。

**跨信号二：Agent 的"证据意识"正在成为独立研究对象。** EHR-RobustGym 指出临床 Agent 的核心失效模式不是检索不到，而是"检索到缺口却仍编造合理答案"。这与 npj 的"复杂度悖论"（GPT-5 配置越复杂，真实诊断未必越好）形成互证：**通用 Agent 的可靠性瓶颈已从能力转向克制（知道何时不该回答）**。方法论上，"证据缺失时的 abstain/escalation 训练"可能比继续堆检索工具更划算。方向 C 的人在环自杀风险升级（C2）恰好是同一哲学的安全治理落地——三条线汇聚成一个概念雏形：**"Epistemic Humility Alignment"（认知谦逊对齐）**，值得作为我方 Clinical Agent 的差异化设计原则。

**跨信号三：多模态基础模型（MedGemma）+ 偏好对齐（EndoCADx）= 医疗 VLM 的下一战场。** MedGemma 开源登上 Nature Medicine，意味着高质量医疗多模态底座已"平民化"；而 EndoCADx 显示瓶颈正转移到"如何让 VLM 输出标准化、可对齐、不幻觉"。**底座开源化 + 对齐精细化**的组合，会把竞争焦点推向"领域偏好数据 + 可验证对齐目标"。

**搜索策略建议：** ① D 方向应新增"AlphaGenome / Evo2 / Borzoi / SpliceAI"等具体模型名作为探针型检索词，比泛搜 foundation model 更能命中评测类新作；② C 方向本月偏薄，建议下周加入 "RLVR / verifiable reward / process reward + clinical" 等可验证奖励新范式检索词；③ A 方向可加入 "AMR foundation model / resistance phenotype prediction" 精准词，弥补纯 mNGS 系综述偏多的问题。总体可关注"对齐范式从 RLHF→RLVR 迁移在医疗的落地"这一潜在爆发点。
