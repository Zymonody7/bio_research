## 方向 A：mNGS + AI 病原检测（2 篇）

**1. 📖 Foundation models and taxonomy inference for metagenomics: A practical review.**
- 期刊：*Computational Biology and Chemistry*（2026-09-18）| DOI: `10.1016/j.compbiolchem.2026.109409`
- 要点：系统梳理宏基因组分类从 k-mer/比对方法走向自监督 DNA 基础模型的进展，沿两条实用轴批评性对比：参考覆盖度（闭集 in-index vs 开集 open-set）与读段特征（短而准 vs 长而噪）。核心结论：在参考库覆盖良好的常见类群上，经典 k-mer 流程仍优于基础模型；基础模型在读段层面的增益"混合且对评测设计高度敏感"。真正合理的收益场景是新颖物种、长/噪声读段、或可接受向高阶分类回退时；embedding 可用于样本级增效与质控。因预训练/长上下文推理的 GPU 与内存开销，实用部署倾向于混合设计：主体读段用快速参考分类，歧义候选用参数高效 adapter 或选择性 embedding 重打分。
- 为什么收：方向 A×D 的交叉综述，直接回答"基因组 FM 何时真的比 Kraken2 有价值"——其"混合回退"判断框架可作为所有 mNGS×FM 论文的评审标尺；与本期 Perseus、phage stress test 形成方法-实证-综述三角。

**2. 📎 Perseus: lineage-aware refinement of Kraken2 taxonomic classification for long read metagenomes.**
- 期刊：*Bioinformatics*（2026-09-16）| DOI: `10.1093/bioinformatics/btag687`
- 要点：Kraken2 在长读段宏基因组上因稀疏/局部 k-mer 匹配而系统性过分类（细阶元假阳性高），尤其在高新颖度微生物组中。Perseus 用多头 CNN 建模 k-mer 证据沿序列的空间分布与层级一致性，把分类重构为"层级置信度估计"问题：为每个标准分类阶元输出校准置信度，据此确认、回退到高阶、或弃权（abstain）。在分类新颖性模拟与真实数据集上大幅降低错误分配率、提升精度与谱系一致性。
- 为什么收：本期最实用的方法件——"校准+回退+弃权"正是 AI 病原检测从论文走向临床报告的关键缺口（检测到属但不到种时系统该说什么）；与下方 CRC-Router 的风险约束路由是同一哲学在两个领域的实现。

## 方向 B：临床 Agent + RAG / 知识图谱（3 篇）

**3. 🔥🔥 EMR: Self-Evolving Medical Multi-Agent System via Experience Mining and Reuse.**
- 预印本：arXiv:2609.15161（2026-09-14）| 作者：Dongsheng Shi, Yue Li, Xin Yi, Linlin Wang
- 要点：现有医疗多智能体依赖静态策略、无持久临床记忆。EMR 构建分层临床经验库（临床原则→诊断模式→代表性病例三层），推理时模拟 MDT 会诊：planner 协调各科室专科 agent，summary agent 汇总决策；关键机制是从多智能体推理轨迹中自动挖掘"正确诊断洞见"与"失败警示"，增量更新经验库以指导后续病例。在医疗推理基准上持续超越 SOTA 多智能体基线；分层经验支持跨专科泛化与跨 LLM 骨干迁移。
- 为什么收：本期头号推荐：临床 agent 从"静态 RAG"走向"经验自进化"的代表——经验库把成功与失败都变成可复用资产，且跨骨干可迁移，是方向 B 记忆机制的范式级工作。

**4. 🔥🔥 Agentic discovery of blood biomarker from distilled private health records.**
- 预印本：arXiv:2610.04749（2026-10-03）| 作者：Seffi Cohen, Liat Antwarg Friedman, Amir Anisman, Ruth Johnson
- 要点：常规血常规（CBC）蕴含新生物标志物，但评估所需的私有病历无法交给前沿 LLM agent。Clalit 在 540 万患者数据边界内为 13 种免疫介导疾病各训练图注意力网络，预测候选 CBC 表达式的 case-control AUC，**仅发布模型权重**作为打分工具，agent 的 propose-score-refine 循环由此接地于真实世界数据而不暴露任何患者数据。外部验证：agent 发现的表达式较文献种子中位提升 4.18 个 AUC 百分点；在三个独立队列中重排三个前沿研究工具的候选，多数比较中改进首选。
- 为什么收："隐私蒸馏的评分器 + 前沿 agent"是医疗 agent 接触真实数据的可复制范式——把私有数据变成可发布的奖励/评分接口，与方向 C 的任务反馈对齐天然衔接。

**5. 🔥 DeepMed Search: An Open-Source Agentic Platform for Medical Deep Research with Introspective Verification.**
- 会议：*IJCAI 2026*（2026-09-01）| DOI: `10.24963/ijcai.2026/978`
- 要点：完全开源的医疗深度研究平台：source-adaptive router 按信息密度把子查询自主分发到 PubMed、Web 或本地图谱知识库；内省验证模块用"因果一致的多智能体辩论"在综合前将检索证据对照诊断逻辑核验，专治复杂长尾查询的"推理漂移"。可自主分解高难度罕见病查询、过滤混杂噪声，分钟级生成带引用的结构化研究报告。开源地址 deepmedsearch.cloud。
- 为什么收：商业黑箱 vs 开源 RAG 的中间路线："glass-box 医疗推理"+内省自检辩论——方向 B 中少有的以基础设施/可复现性为卖点的 IJCAI 级平台论文。

## 方向 C：RLHF 医疗对齐（3 篇）

**6. 🔥🔥 RASPER: Reward-Aligned Summarization of Clinical Notes for EHR Outcome Prediction.**
- 预印本：arXiv:2610.02979（2026-10-02）| 作者：Arya Hadizadeh Moghaddam, Mohsen Nayebi Kerdabadi, Chen Chen, Dongjie Wang
- 要点：EHR 出院小结的通用摘要为流畅性优化，常遗漏决定性证据。RASPER 用**下游预测器损失派生的奖励**做强化学习（from prediction feedback，无临床医生偏好标注），直接对齐摘要与临床任务；纵向编码器把结构化编码转为软提示注入患者上下文，奖励多模态预测质量以鼓励保留"互补而非重复"结构化编码的患者特异证据。在 MIMIC-III/IV 的再入院预测与用药推荐上持续超越强基线。
- 为什么收：方向 C 的范式信号：医疗对齐的奖励源正从"人类偏好"转向"任务反馈"——RL 机制被复用为多模态证据筛选器，无标注即可对齐，可移植到任何"文本摘要→结构化预测"管线。

**7. 🔥🔥 Neurosymbolic Alignment for Physiologically-Safe Clinical Language Models.**
- 预印本：arXiv:2608.24534（2026-08-25）| 作者：Abdulhady Abas Abdullah, Erik Cambria, Milena Zivkovic
- 要点：临床 LLM 会给出"事实合理但生理不安全"的建议。该框架将 7B 临床 LLM 与基于 847K 节点生物医学知识图谱的 HGNN"生理世界模型"耦合：用稳态约束、多跳路径合理性、药物相互作用惩罚为候选回复打分，排名驱动迭代 on-policy ORPO。在 2,500 场景的临床安全基准 CSB 上：安全性 CSS 69.5%→90.8%（+21.3pp），医师评估有害率 14.1%→5.1%，药物相互作用违规 72.8%→91.6%；独立规则引擎评分 RSS 86.4%（与 CSS 一致性 r=0.97）。以 10 倍参数劣势超越 GPT-4（5-shot）全部安全指标，且优于推理时自纠错管线 11.4pp；合成 EHR 噪声下保留 84.2% CSS。
- 为什么收："符号世界模型做奖励模型"路线的最强实证——KG 约束替代人类偏好评分，同时给出可审计的规则一致性验证；与 RASPER 共同定义方向 C 的"结构化奖励"双臂。

**8. 🔥 Positive-Unlabeled Preference Optimization For Chest X-ray Report Generation (PU-DPO).**
- 预印本：arXiv:2608.05341（2026-08-05）| 作者：Yuta Kobayashi, Pradyun Ramesh, Muhammad Ahmed Chaudhry, Vincent Jeanselme
- 要点：放射报告存在"遗漏噪声"——临床存在但未被书写的发现（如 ICU 胸片以监护导管为主诉时心影增大常被省略），标准训练使 VLM 继承漏报。PU-DPO 把偏好目标重构为正例-未标注（PU）学习：缺失提及视为"未标注"而非真负例；用对模型回复的编辑构造对比对（显式提及 vs 省略某发现），有视觉证据时"提及"版本自然更受偏好。在半合成实验与有仲裁标签的真实胸片基准上一致提升检出率与隐藏阳性恢复，对遗漏噪声更鲁棒。
- 为什么收：把 PU 学习引入 DPO 修正医疗监督数据的系统性漏标——"未标注≠负例"这一洞察直指所有用回顾性临床报告做偏好对齐的工作的根本缺陷。

## 方向 D：基因组基础模型（3 篇）

**9. 🔥🔥 Kidzoi Enables Cell-Type-Specific Regulatory Activity and Variant Effect Prediction in Kidney.**
- 预印本：bioRxiv 2026-10-04 | DOI: `10.64898/2026.09.28.746288` | 作者：Arif Rather, Dongwon Lee
- 要点：Sequence-to-function（S2F）模型受初始训练数据集束缚，从头训练代价高昂。Kidzoi 用人类肾脏单核染色质可及性数据对预训练 Borzoi 做**迁移学习**，得到肾细胞类型特异 S2F 模型：准确预测细胞类型特异染色质可及性，调控变异效应预测较现有模型提升 10–23%；有效优先化 eGFRcr-cys 的 GWAS fine-mapped 因果变异并解析其细胞类型特异性。消融显示仅 32–64 kbp 局部上下文（全输入的 6–12%）即足以支持 VEP；多任务模型以显著更低算力达到与单任务相当的性能。
- 为什么收：本期方向 D 头号推荐："预训练基础模型 + 组织特异小数据迁移"取代从头预训练的可行性范本——10–23% VEP 增益 + 6–12% 上下文充分性结论，对基因组 FM 的实用化路径（算力民主化）意义直接。

**10. 📎 Tangermeme: a toolkit for understanding cis-regulatory logic using deep learning models.**
- 期刊：*Nature Methods*（2026-10-08）| DOI: `10.1038/s41592-026-03254-z` | 作者：Jacob Matthew Schreiber
- 要点：基因组深度学习模型的价值在于预测性能达标之后如何被用于生物学发现。tangermeme 是针对基因组深度学习"模型之外一切"（everything-but-the-model）的高度优化工具包，将模型学到的顺式调控模式蒸馏为人类可解释的洞见（解释、归因、干预分析等工作流的统一实现）。
- 为什么收：方向 D 的解释层基础设施件（Nature Methods 级）：FM 军备竞赛之后，"从模型中提取可检验的调控假设"成为新瓶颈——该工具包是任何 S2F/基因组 FM 论文做机制解释的标准件。

**11. 🔥 The phage stress test: a proving ground for genome language models in biological prediction.**
- 预印本：bioRxiv 2026-09-24 | DOI: `10.64898/2026.09.23.753910` | 作者：Emily M. Layton, Michael L. Bernauer, Laura D. Weinstock, Eric M. Small
- 要点：噬菌体小基因组 + 数十年实验文献构成信息密集的基准，且大部分位于 GLM 训练所用序列库之外。以 Evo2 为对象，用两个模型噬菌体（ssRNA 噬菌体 MS2、ssDNA 噬菌体 ΦX174）的实验突变数据检验：Evo2 序列对数似然能捕捉序列层约束（终止密码子普遍受罚、同义替换似然高于非同义），对同义密码子的区分仅弱解释于宿主密码子使用偏好；**但这些能力未能转化为稳健的生物学预测**——在 MS2 上 ΔSLL 无法区分功能性与非功能性突变。
- 为什么收：方向 D 的清醒剂：GLM 会生成可行基因组 ≠ 会预测局部突变效应——"生成能力与编辑预测能力解耦"是基因组 FM 评测的分水岭结论，直接呼应综述（本期 #1）对评测设计的批评。

## 方向 F：多模态临床 Agent（3 篇）

**12. 🔥🔥 See, Measure, and Reason: Learning Visually Grounded Reasoning in Pathology (ASPECT).**
- 预印本：arXiv:2609.34277（2026-09-28）| 作者：Chengyang Zhang, Wenchuan Zhang, Bo Li, Mengran Li
- 要点：病理评估依赖对组织图像细粒度视觉细节的识别，VLM 的感知不足会导致错误的细胞学观察——即使最终答案正确也可能错。ASPECT 对细胞形态与丰度做显式监督：通过病理特征重建、细胞特征对齐、计数监督训练中间视觉 token；三阶段 SFT 教会模型"感知→生成视觉 token→推理"，再以答案正确性 + 与实测计数一致性为奖励做 RL。同时提出 PathoVernier 基准：5 个病理数据集、759 道专家审阅问题、4 类细胞组成任务，同时评测最终答案与中间测量值以暴露"答案对但过程错"。ASPECT 相对最强基线 Gemini-3.1-Pro 提升约 19.2%，相对 Qwen3-VL-8B 骨干提升 99.3%，计数错误（RAWR）分别降低 28.1%/42.7%。
- 为什么收：本期方向 F 头号推荐："过程监督 + 可测量中间量"直击多模态临床 agent 的感知地基——RAWR 这类"正确答案内的隐藏错误"指标应成为所有临床 VLM 评测的必报项。

**13. 🔥 CRC-Router: Risk-Constrained Routing for Medical Agentic AI Systems.**
- 预印本：arXiv:2609.30714（2026-09-25）| 作者：Xueyang Li, Mingze Jiang, Gelei Xu, Jun Xia
- 要点：医学影像 agent 的自主错误会传导至下游临床决策，安全部署的关键不是单纯性能，而是可靠的路由机制：何时自主执行、何时上报复核。CRC-Router 融合多个互补不确定性信号 + 预测分数构成 per-finding 路由特征，用轻量风险模型映射为错误接受风险，再用**共形风险控制（CRC）**在用户指定风险目标下校准接受阈值。在 ChestX-ray14 多发现分诊上取得最强风险-覆盖率权衡，既可独立作为路由层，也可即插即用于 SOTA 的 MedRAX agent。
- 为什么收："可保证风险上限的自主性边界"是医疗 agent 监管落地的硬需求——共形预测给 agent 装上统计学承诺的"刹车"，与 Perseus 的弃权机制跨领域同构。

**14. 🔥 Autonomous radiotherapy planning via agentic orchestration using a multimodal TPS-integrated compound AI platform.**
- 期刊：*Machine Learning in Health*（2026-06-08）| DOI: `10.1088/3049-477x/ae7978` | 作者：Austen Matthew Maniscalco, Yang Kyun Park, Sean J. Domal, Mu-Han Lin
- 要点：把剂量预测作为 agent 可调用工具嵌入放疗计划系统（TPS），实现端到端、全自动、通用的放疗计划编排：剂量预测用于目标函数初始化，解决了此前 LLM 计划系统依赖人工整理模板与手动指定的约束，确立了 compound AI 全自主 RT 计划的可行性。
- 为什么收：多模态临床 agent 从"诊断辅助"迈向"治疗执行编排"的少数闭环实例——agent 编排 + 领域专用工具（剂量预测器）+ 生产系统（TPS）集成，是方向 F 商业化路径的参考架构。

## 跨界发现（Direction X，1 篇）

**15. 🔥 Omics data discovery agents: Agent-supported retrieval, reanalysis, and synthesis of published omics data.**
- 期刊：*PLoS Computational Biology*（2026-10-06）| DOI: `10.1371/journal.pcbi.1014822` | 作者：A. Hutton, Jesse G. Meyer
- 要点：生物医学文献中海量组学数据在功能上不可复用。该 agent 框架让 LLM agent 调用工具链：抓取组学研究、抽取元数据、识别并下载已发表数据、执行容器化定量流程、跨研究综合结果；以 MCP server 暴露容器化分析工具。在语料规模上编目数千篇 PMC 文章的数据集引用（作者明确声明为描述性输出而非验证的抽取精度）；五个端到端再分析（蛋白组 DDA/DIA + bulk RNA-seq）全部完成，复现原作者沉积丰度的样本级相关性达 0.85–0.997，均有人工引导记录。
- 为什么收："文献→数据→再分析"全自动管线的首个可信实现（PLoS CB）——对做 mNGS/FM 数据再利用的研究者是直接可用的基础设施；其"诚实报告系统输出 vs 验证指标"的写法也值得借鉴。

## 🧠 前沿洞察与头脑风暴

**三大跨领域信号正在合流：**

其一，"知道何时不回答"成为横跨领域的独立设计轴。本期 Perseus（宏基因组分类的校准-回退-弃权）与 CRC-Router（共形风险控制约束的临床 agent 路由）在两个完全不同的领域实现了同一哲学：把输出从"点预测"重构为"带置信保证的决策"。综述（#1）对基础模型"混合回退"的呼吁与之呼应。共形预测类方法可能很快成为医疗 agent 的标配安全层，值得在后续检索中显式加入 conformal / selective prediction / abstention 关键词监控。

其二，医疗对齐的奖励源正经历"去人类化"。RASPER 用下游任务损失、Neurosymbolic Alignment 用 KG 生理约束、PU-DPO 用"遗漏即未标注"的重构——三者都不再依赖医生偏好标注。更值得注意的是 #4 的隐私蒸馏评分器：把 540 万患者数据压成可发布权重，等于把"真实世界证据"变成 agent 可消费的奖励接口。"私有数据→蒸馏评分器→开源 agent 循环"可能是医疗 AI 突破数据壁垒的可复制范式。

其三，基因组 FM 进入"后预训练"阶段。Kidzoi（Borzoi 迁移）、Tangermeme（解释工具链）、phage stress test（Evo2 生成可行基因组却预测不了局部突变效应）共同指向：军备竞赛式从头预训练的价值在衰减，取而代之的是"预训练底座 + 组织/任务特异轻量适配 + 可解释蒸馏"的三层栈。"生成能力≠编辑预测能力"的解耦结论应成为方向 D 的评测底线。

**空白点：**① mNGS×Agent 完全空缺——检测出的分类群如何与宿主背景、临床指南联结成可审计的报告 agent，无人做；② RL/对齐式微调在基因组 FM 上零文献——phage stress test 恰好证明裸 GLM 不懂突变效应，用实验 fitness 数据做偏好/奖励对齐是明确机会；③ 风险约束路由仅覆盖影像分诊，治疗推荐 agent 的自主性边界仍是无人区。
