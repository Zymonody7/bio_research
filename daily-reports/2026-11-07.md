- Sriram A, Luo T, Zhang L, Kim S, Park HJ
- 单细胞基础模型被广泛跨组织/疾病/扰动筛选/平台迁移，但**"模型对自己预测可靠性的自我评估"能否迁移**从未被系统研究。作者在**10 个扰动预测系统**上定义并测量 **reliability transfer**：可靠性迁移**在源-目标对之间差异巨大，且无法从预测性能推断**——**预测迁移与可靠性迁移是两种不同的泛化形式**。进一步提出 **reliability-attribution fingerprints**（严格交叉拟合的 SHAP 上下文级签名），量化可靠性估计器如何组合"生物学信号 vs 上下文信号"。

- 把稀疏自编码器（SAE）特征间的**模型内部因果电路**（在源层置零一个 SAE 特征、测量下游全部特征变化）应用于 **Geneformer V2-316M 与 scGPT whole-human**，4 种条件、**96,892 条消融边 / 80,191 次前向**。发现：**抑制性主导**（源激活支撑下游目标的边占 65.5–89.4%）；标注选中源特征的边共享 GO/KEGG/Reactome/STRING/TRRUST 通路的比例 **50.9–68.5%（置换零假设的 2.9–6.2 倍）**；**跨模型共识得到 1142 个架构不变的领域对（10.6 倍富集，P<.001）**；电路边幅度**只能解释 <1% 的边际驱动基因共表达方差**（说明图编码了超越双变量相关的结构）；对 ENCODE ChIP-seq 先验，电路预测的 TF→target 对**富集 2.06 倍**，且直接受 ChIP-seq 支持的对在 CRISPRi 验证中效应大 10–30 倍。
- **跨界价值：单细胞基础模型的可解释性正从'注意力可视化'走向'可证伪的因果电路 + 实验验证'——这条路线可直接迁移到基因组基础模型（D 方向）。**

## 🧠 前沿洞察与头脑风暴

**1. 从"预测正确"到"知道自己什么时候错"。** 本轮 X 方向的两篇构成一组强信号：reliability transfer 独立于 prediction transfer，SAE 因果电路又能跨模型收敛出架构不变的领域对。合起来指向一个新评测范式——**基础模型的迁移能力要拆成"性能迁移"与"置信结构迁移"两条曲线**。对临床 agent 而言，后者才是可审计性的根：一个跨机构部署的模型如果可靠性自评不迁移，它的"低幻觉"宣称只在原域有效。**建议在 D/F 方向检索里新增 `calibration AND foundation model AND (genomic OR clinical)`、`uncertainty quantification AND scFM` 两组词。**

**2. Agent 的失败模式正在从"答错"变成"不肯停"。** Hard to Halt 显示：模型非 agent 模式能识别 91% 的缺陷，一旦交给浏览器 agent 就几乎全部照常提交——**错误由交互层引入而非推理层**；JAMIA 的 code status 研究则显示反思/多 agent 复核既花钱又可能变差。两条合起来提示一个空白：**临床 agent 缺一套"恰当拒绝（appropriate withholding / abstention）"的标准化基准**，现有 benchmark 全在测完成率。这可能是 B 方向下一个可发论文的切口。

**3. 偏好优化的"去人工化"三条路线并进。** DiaWhisper-DPO 用**模型自身失败当 rejected**（零标注成本），AnyMetric 用**指标即偏好**（绕开奖励模型），PRISM2 用**对话监督**（把报告变成偏好信号）。医疗 RLHF 的瓶颈是标注成本与临床一致性，这三条正好各砍掉一个成本项。**建议 C 方向补搜 `failure mining / self-generated negatives / reward-free preference`。**

**4. 方向 A 仍是最大的 white space。** 连续两日"mNGS 序列判读 agent"命中为零，而 D 方向的 DNA 语言模型（Chiron3D、HiCP2GAN、GLM 综述）已能给出核苷酸级归因。**把 D 的序列归因能力接到 A 的病原判读上（可解释的病原/耐药位点证据链）是明确的交叉机会**——检索上可用 `(k-mer OR sequence attribution) AND (pathogen OR resistance) AND (language model OR foundation model)` 试探。

**5. 检索策略建议。** ① 本轮 PubMed 对 B/F 的召回明显优于 arXiv（arXiv 兜底仅在 C 触发一次），但**预印本常以 medRxiv/bioRxiv 形态先于 arXiv 出现**，后续应把 `medrxiv OR biorxiv` 纳入 PubMed 查询词；② **语料级去重不可省**——本轮靠它拦下 7 篇重复（47% 的初选是重复），建议把 `final_select` 的三重校验固化为管线前置步骤；③ 方向 D 需更严格的"genomic FM only"过滤，仍混入少量蛋白/分子性质研究，可考虑在排除词表中加入 `protein AND NOT (genom|DNA)` 的硬规则。

**本周一句话：** 单细胞/基因组基础模型进入"可信度归因"阶段，临床 agent 进入"何时该停手"阶段——两条线的交点（**具备可靠性自评与拒绝能力的基因组/多模态 agent**）目前几乎无人占位。
