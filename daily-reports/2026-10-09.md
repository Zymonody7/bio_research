## 方向 A：mNGS + AI 病原检测（2 篇）

**1. 🔥 Nanopore metagenomic sequencing links clinically relevant resistance determinants to pathogens**
- 期刊：*Microbial Genomics*（2026）| DOI: `10.1099/mgen.0.001834` | PMID: 42766345
- 要点：培养非依赖的宏基因组能直接从临床样本检出质粒介导的 AMR 基因，但其临床意义取决于细菌宿主与基因组背景。本文利用 Nanopore 测序天然编码的甲基化表观遗传信号，从临床宏基因组中直接推断质粒-宿主关联，把"耐药基因"与"携带它的病原菌"重新连起来。
- 为什么收：mNGS 从"检出什么"走向"归因到谁"的关键方法学进展——AMR 归因是 mNGS 临床化的核心瓶颈，表观遗传信号是一个被低估的正交数据源。

**2. 📖 Metagenomic next-generation sequencing in the diagnosis of viral encephalitis**
- 期刊：*World Journal of Virology*（2026）| DOI: `10.5501/wjv.124097` | PMID: 42781247
- 要点：综述 mNGS 在病毒性脑炎病因诊断中的价值——靶向 PCR/血清学/培养/多重 panel 依赖预设病原体、采样时间与标本生物学，大量病例病因未明；mNGS 可无预设靶标地 interrogate 脑脊液中的 DNA/RNA，检出意外、罕见、机会性或新发病毒。
- 为什么收：作为 mNGS 临床落地场景（中枢神经系统感染）的系统性综述，是方向 A 的背景参考。

## 方向 B：临床 Agent + RAG / 知识图谱（2 篇）

**3. 🔥🔥 KGR-MAS: Knowledge Graph-Enhanced Multi-Agent LLM Framework for Evidence-Based Medical Diagnosis and Clinical Decision Support**
- 期刊：*IEEE Journal of Biomedical and Health Informatics*（2026）| DOI: `10.1109/JBHI.2026.3740738` | PMID: 42848569
- 要点：针对 LLM 在复杂临床场景中的推理偏差、信息瓶颈与适应性不足，提出集成控制回路：(1) 用 KG 推导出的诊断路径做可执行子任务分解与动态智能体分配；(2) 用这些 KG 推理路径同时约束/引导各 agent 的执行。
- 为什么收：**KG 不再只是检索源，而是 agent 编排的控制策略**——这是本期最强的架构级信号（与方向 X 的 HyGRAIL 同构）。

**4. 🔥 MES: A Multi-Agent Evidence Synthesis System for Medical Decision-Making**
- 期刊：*medRxiv* 预印本（2026-09-15）| DOI: `10.64898/2026.09.15.26362921` | PMID: 42818103
- 要点：现有自动证据合成系统多局限于文献检索+摘要。MES 协调 6 个专职 agent：分解临床问题 → 检索文献与试验证据 → 生成问题特异的真实世界数据（RWD）查询 → 融合，输出 source-grounded 的医学证据合成。
- 为什么收：把"文献证据 + 临床试验 + 真实世界数据"三源纳入同一个多智能体流水线，弥合了 literature-RAG 与真实临床数据之间的断层。

## 方向 C：RLHF 医疗对齐（3 篇）

**5. 🔥🔥 ResidencyRL: Reinforcement Learning in Simulated Clinical Environments**
- 来源：arXiv:2608.07418（cs.AI，2026-08-07）| DOI: `10.48550/arXiv.2608.07418`
- 要点：在模拟临床环境中用强化学习训练/评估临床决策策略——把医疗 RL 从"偏好对齐"扩展到"在交互式诊疗环境中学习"。
- 为什么收：方向 C 目前以静态偏好优化为主，本文代表"临床环境交互式 RL"这条更接近 RL 本义的路线，与 agentic 临床趋势（方向 F）天然衔接。

**6. 🔥 ConRub-Med: Reinforcement Learning with Consensus Rubrics for Open-Ended Medical Question Answering**
- 来源：arXiv:2608.10996（2026-08-11）
- 要点：rubric 引导的强化学习：共识标准构建 + 三态（Three-State）打分，替代传统标量奖励；在 9 个基准中的 6 个上排名第一，医学与泛化平均分均最高。
- 为什么收：与此前收录的 InfiMed-ORBIT（2510.15859）同属"rubric 医学对齐"路线——共识化 rubric 奖励正在成为开放式医疗对齐的主流解法。

**7. 🔥 CLIN-LLM: A safety-constrained hybrid framework for clinical diagnosis and treatment generation**
- 期刊：*PLOS ONE*（2026）| DOI: `10.1371/journal.pone.0348611` | PMID: 42658861
- 要点：安全约束混合管线：多模态患者编码 + 不确定性校准 + 医学 grounding，针对症状-疾病分类与治疗推荐中 LLM 缺乏医学依据、不量化不确定性导致的不安全输出。
- 为什么收：不确定性校准作为对齐目标（而不仅是后处理）的代表工作。

## 方向 D：基因组基础模型（3 篇）

**8. 🔥🔥 LAMBDA: a prophage detection benchmark for genomic language models**
- 期刊：*NAR Genomics and Bioinformatics*（2026）| DOI: `10.1093/nargab/lqag103` | PMID: 42713011
- 要点：基因组序列模型是计算生物学新前沿，但其 embedding 至今未展现自然语言/蛋白语言模型同级的预测力。现有 DNA-LM 基准几乎都聚焦真核调控元件分类；LAMBDA 提出**噬菌体前噬菌体检测**基准，检验基因组 LM 在原核/病毒区间的真实表征能力。
- 为什么收：直接回应"genomic LM 的 embedding 到底行不行"这一领域核心质疑，基准设计（离开真核调控舒适区）思路值得借鉴。

**9. 🔥🔥 A Transferable Genomic Language Model Framework for Fungal Gene Essentiality Prediction**
- 来源：*bioRxiv* 预印本（2026-09-03）| DOI: `10.64898/2026.09.03.749190` | PMID: 42818247
- 要点：检验基因组语言模型 Evo2 的 DNA embedding 能否预测真菌必需基因（抗真菌靶点发现的核心表型）。发现：模型性能瓶颈不在任务/表型复杂度，而在数据与表征本身——为跨物种可迁移的基因组 LM 框架提供了边界条件。
- 为什么收：Evo2 embedding 作为通用特征提取器向真菌界迁移的系统评估，是"genomic FM 即基础特征"路线的关键证据（无论正反）。

**10. 🔥 PlantGFM: A Genomic Foundation Model for Discovery and Creation of Plant Genes**
- 期刊：*Advanced Science*（2026）| DOI: `10.1002/advs.75772` | PMID: 42160034
- 要点：将 Hyena 算子应用于植物导向的基因组基础模型，用于植物基因的发现与从头创造；突破传统杂交/诱变/CRISPR 编辑受限于天然序列多样性的瓶颈。
- 为什么收：基因组 FM 从"预测"走向"生成与创造"的植物界代表（与人类/微生物基因组 FM 并行的第三极）。

## 方向 F：多模态临床 Agent（3 篇）

**11. 🔥🔥 AgentEYE: An autonomous multimodal AI agent for evidence-grounded ophthalmic diagnosis**
- 期刊：*Cell Reports Medicine*（2026）| DOI: `10.1016/j.xcrm.2026.102969` | PMID: 42556343
- 要点：眼科多模态诊断需整合眼底照相、B 超与医学证据，现有 AI 多为单任务或弱 grounding。AgentEYE 是可审计的多模态 agent：把眼科图像路由到专职的眼底/B 超工具，检索指南/网络证据，合成证据接地的诊断报告；在 302 例内部基准上诊断表现优于基线。
- 为什么收：**"可审计 + 证据接地 + 工具路由"**三要素齐备的多模态临床 agent 标杆，正式发表于 Cell 子刊。

**12. 🔥🔥 MIRA: Medical Image Reflection for Agentic Diagnosis**
- 来源：arXiv:2608.10827（cs.CV，2026-08-11）| DOI: `10.48550/arXiv.2608.10827`
- 要点：以"医学图像反思（reflection）"机制支撑 agent 化诊断——让诊断 agent 对自己的读片结论进行迭代式自我校验，而非一次性出报告。
- 为什么收：把 LLM agent 的 self-reflection 直接作用于视觉读片环节，补上多模态临床 agent 的"视觉自我纠错"短板。

**13. 🔥 EviDx: Evidence-Aware Active Diagnosis with Scaffolded LLM Agents**
- 来源：arXiv:2608.24570（cs.AI，2026-08-25）| DOI: `10.48550/arXiv.2608.24570`
- 要点：证据感知的主动诊断：scaffolded LLM agent 在诊断过程中主动选择下一步最有信息量的检查/证据获取动作（active diagnosis），而非被动汇总已有信息。
- 为什么收："主动选择检查"对应真实临床的检验开立决策，是诊断 agent 从"解释器"走向"决策者"的标志。

## 🧩 跨界发现

1. **"KG 作为 agent 控制策略"范式跨域收敛**：KGR-MAS（临床诊断）与 HyGRAIL（科学假设发现）都把知识图谱从"检索语料"升级为"子任务分解 + 动作编排的控制回路"。同样的抽象同时出现在两个领域，说明这可能是一个正在标准化的 agent 架构层。
2. **基因组 LM 进入"embedding 即特征"的冷静期**：LAMBDA（新基准拷问 embedding 真实力）与真菌必需基因研究（Evo2 迁移的边界条件）共同指向——基因组 FM 的价值正从"端到端惊艳"转向"作为可迁移特征提取器的诚实评估"。这与蛋白 LM 三年前的发展轨迹同构，但注意：用户已明确排除蛋白 LM 方向，此信号仅用于判断基因组 LM 的成熟度坐标。
3. **Rubric 化医疗对齐正在定型**：ConRub-Med 的"共识 rubric + 三态打分"与此前收录的 InfiMed-ORBIT 同路——开放式医疗对齐正放弃标量奖励模型，转向可验证的原子化 rubric 共识。
4. **mNGS 与 AI 的结合点仍在"归因"而非"检出"**：本期方向 A 未检出强 AI 驱动的 mNGS 新工作，最接近的是 AMR 的质粒-宿主归因（表观遗传信号）。检出环节 AI 已趋饱和，归因/解释环节仍是空白。

## 🧠 前沿洞察与头脑风暴

**信号一：Agent 架构的"控制层"正在从 prompt 转向图谱。** KGR-MAS 与 HyGRAIL 同月出现、同构设计——知识图谱不再是 RAG 的检索后端，而是决定"下一步派哪个 agent、做什么子任务"的编排策略。可以合理推测：未来 6 个月，"KG-as-policy" 会成为临床 agent 论文的标准组件，真正的差异化将来自**图谱的构建来源**（指南/教科书 vs 真实世界数据 vs 自动挖掘）。建议关注：谁能把诊疗指南（如 IDSA/中华医学会指南）结构化成可执行的诊断路径图谱——这可能是下一个高引 benchmark 或数据集的空白位。

**信号二：基因组 LM 的"表征信任危机"与出路。** LAMBDA 的立论很尖锐：DNA-LM 的 embedding 至今未达到 NLP/蛋白 LM 的预测力水平。真菌必需基因研究给出了一个微妙的补充——瓶颈可能不在任务复杂度，而在预训练数据与目标本身。头脑风暴：mNGS 社区（方向 A）与基因组 FM 社区（方向 D）几乎互不引用，但前者手握海量临床宏基因组的真实"功能标签"（培养结果、药敏、宿主归因），后者正缺这类 grounding。**用 mNGS 临床数据做基因组 LM 的下游验证/继续预训练，是一个明显但无人占位的交叉白 space。**

**信号三：Rubric 共识奖励的可复现性问题。** ConRub-Med 报告 9 基准中 6 个第一，但 rubric 由"共识构建"而来——共识如何达成（专家人数、专科、投票规则）直接决定奖励分布。这一环节目前普遍报告不足，是审稿人与复现者会盯住的软肋，也是做"rubric 对齐可复现性基准"的机会。

**信号四：主动诊断（active diagnosis）可能重写评测范式。** EviDx 让 agent 主动选择下一步检查——这把评测从"给全信息问答案"变成"问你下一步开什么检查"，更接近真实临床，也更难作弊。建议下期检索加入 "test ordering / workup strategy / sequential diagnosis" 关键词，追踪这条评测演化线。
