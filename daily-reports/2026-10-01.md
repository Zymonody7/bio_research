## 🧠 前沿洞察与头脑风暴

**本周三条交叉信号值得注意。**

第一, **对齐正在从"离线RLHF"走向"场景化偏好学习"**。本周 C 方向三篇论文构成完整链条: 合成纵向对话做康复场景偏好对齐 (C1) → LLM judge 验证能否复现专家判断 (C2) → 上下文老虎机在ICU通气决策中在线收集偏好 (C3)。医疗偏好数据天然稀缺且敏感, "合成对话+在线bandit+judge验证"正在成为替代真实标注的三件套。值得追问: 这套管线能否移植到 mNGS 报告审核或抗菌药物推荐这类高风险场景?

第二, **基因组 FM 遇到"归纳偏置天花板"**。D2 论文给出尖锐证据: 掩码扩散模型在变异预测上刷分很高, 但向功能泛化迁移失败——这意味着大量 mask-based 预训练工作的 benchmark 优势可能是任务捷径而非真理解码。应对路线已分化: D1 (GenoME) 转向 MoE + 多模态调控信号, D3 (RNASeek) 引入 RL 微调, D4 直接用 FM 嵌入做病毒识别。白色空间在于: **没人系统回答"什么样的预训练目标才编码生物学机制而非统计规律"**——这可能是2027年genomic FM的主战场。

第三, **知识层 (KG) 正在成为 agent 的记忆底座**。B1 (KG补全ambient笔记) 和 B2 (LLM控制的动态KG更新) 加上 F1 (MedTRACE的工具接地), 三条线指向同一架构收敛: 临床 agent = 感知(多模态) + 记忆(KG) + 行动(工具) + 对齐(偏好)。Mantis 的机理仿真预训练则是"仿真即记忆"的极端形式。
