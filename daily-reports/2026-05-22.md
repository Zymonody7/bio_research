- **与你项目的关联**：EvoStruct 的结构-进化先验融合策略为蛋白质语言模型在抗体设计中的应用提供了新范式，尤其适用于你的蛋白工程管线中 CDR 设计的精度和多样性优化。

## 🧬 E. 基因组大模型 (2篇)

### 8. 🔥🔥 EvoLen: Evolution-Guided Tokenization for DNA Language Model
**Huang et al.** — arXiv 2026
- One-sentence takeaway: 提出融合跨物种进化信号和长度感知解码的 DNA 分词器，通过 partition-and-merge 策略将功能序列模式（如调控基序）的保留显著提升，在多个 DNA LM 基准上匹配或超越标准 BPE。
- **与你项目的关联**：EvoLen 揭示的"分词即归纳偏置"对基因组基础模型开发具有深刻启示——进化引导的分词策略可让你的 DNA 语言模型更精确地捕获功能相关变异，直接提升变异效应预测的生物学可解释性。
- 📎 [arXiv:2604.08698](https://arxiv.org/abs/2604.08698)

### 9. 🔥 MergeDNA: Context-Aware Genome Modeling with Dynamic Tokenization through Token Merging
**Author et al.** — AAAI 2026
- One-sentence takeaway: 提出层次化架构联合优化动态基因组分词器和潜在 Transformer，通过 Merged Token Reconstruction 和 Adaptive Masked Token Modeling 预训练任务，在 DNA 基准和多组学任务上超越现有方法。
- **与你项目的关联**：MergeDNA 的动态分词+合并策略解决了固定 k-mer 方法的上下文盲区问题，为你的基因组基础模型在复杂多组学场景下的表征学习提供了新思路。
- 📎 [arXiv:2511.14806](https://arxiv.org/abs/2511.14806)

## 🧠 前沿洞察与头脑风暴

### 跨方向信号

本日论文呈现出四条清晰的交叉脉络：

**1. Agent技能编排成为新基础设施。** MACRO（自我进化技能发现）、MolClaw（三层技能架构）、Vibe Medicine（1000+技能集合）三个来自不同方向的独立工作不约而同地聚焦于"技能"的表示、组织和进化。这标志着 AI agent 研究的重心正从"单一模型能力"转向"技能编排与持续学习"。对你的临床agent而言，关键在于设计可组合、可审计、可进化的技能图谱，而非堆砌模型参数。

**2. 分词策略成为基因组/蛋白质模型的瓶颈突破点。** EvoLen 和 MergeDNA 分别从进化引导和上下文感知两个角度重新思考了生物序列的分词问题。长期以来，k-mer 和 BPE 被视为"够用"的默认选择——这两项工作强有力地论证了：分词策略深刻影响模型对功能序列模式的捕获能力。这对于团队正在训练的基因组基础模型具有直接的架构参考价值。

**3. 多目标对齐从理论走向临床验证。** MODPO 的6维度心理治疗对齐不仅提出了方法，更重要的是完成了从患者偏好调研→多目标优化→盲法临床评估的完整验证链。结合 ProMedical 的细粒度标准注入，医学 RLHF 的评估方法论日趋成熟。这为你的临床 LLM 安全评估体系提供了可复用的"调研-优化-评估"三阶段范式。

**4. 从"图像理解"到"空间推理"——医学多模态的下一场战役。** SpatialMed 揭示了一个被忽视的事实：当前医学 VLM 擅长2D图像识别，但几乎完全缺乏3D空间理解能力。MARL-Rad 则从强化学习角度将空间推理嵌入放射科工作流。这预示着医学多模态的下一个突破点在于将"看图说话"升级为"空间推理+临床决策"。

### 新兴概念

- **经验驱动技能发现（Experience-driven Skill Discovery）**：MACRO 提出的概念，让 agent 从临床交互历史中自动发现并固化有效工具使用模式。
- **进化引导分词（Evolution-Guided Tokenization）**：EvoLen 开创性地将跨物种保守性信号编码进 DNA 分词过程，为"归纳偏置即架构"提供了新注脚。
- **人-AI协同科研（Vibe Medicine）**：区别于"AI替代人"或"AI辅助人"的传统框架，Vibe Medicine 提出"人-指导-AI-执行"的新型协作关系。

### 研究空白（White Space）

- **临床 Agent 的安全失效模式系统研究**：尽管 MACRO 和 MolClaw 展示了 agent 编排能力，但多层次技能组合带来的新型安全风险（如技能间交互导致的不安全行为）几乎无人涉足。
- **进化信息 + 基因组 FM 的深度融合**：EvoLen 仅在分词层面引入进化，如何将进化约束深度嵌入预训练目标和架构设计，仍有大量空白。
- **多目标医学对齐的统一评估框架**：MODPO 和 ProMedical 各自提出了评估方法，但缺乏跨方法、跨场景的统一医学对齐基准。

### 搜索策略建议

- 增加对 **ICLR 2026 / ICML 2026 / NeurIPS 2025 proceedings** 的定向监控，已有多篇相关工作被顶会收录
- 关注 **"agentic + workflow + biology"** 交叉关键词，agent 技能编排正在成为生物信息学和药物发现的新范式
- 持续追踪 **Evo 2 / ESM-3 等旗舰模型的后续改进**工作，这些是蛋白/基因组基础模型方向最重要的信源
