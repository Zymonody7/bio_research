## 🔗 跨界信号

1. **B×C：证据/本体正变成训练奖励。** FoG 的 ECPR（证据覆盖过程奖励）与 Ontology-CUI-GRPO（本体重叠软验证器）分别从"检索证据"和"知识结构"两个方向把 KG 写进 RL 目标——RAG 评测正从"生成后审计"前移到"训练时奖励"。
2. **C×F：对齐粒度走向 token 级与边界样本。** TD-DPO（token 级差异加权）与 MedCBR（能力边界偏好 + 熵控 rubric）都不再满足于序列级/结果级奖励，说明医学对齐已进入"定位失败 span、只改该改的部分"的精细化阶段。
3. **D×A：短读长 reference-free 注释。** BBERT 这类核苷酸 LM 不查数据库直接判 domain/reading frame，与临床 mNGS 中 unclassified reads 比例高的痛点天然契合，可能改写病原判读流程的中间环节。
4. **X→F/评测范式：三段式验证成为标杆。** Nature Cancer irAE 工作把"回顾性 → 前瞻静默 → 随机交叉"跑全，配合成本核算（$0.02/条）——后续临床智能体论文若只有回顾性内部验证，说服力将显著下降。

## 🧠 前沿洞察与头脑风暴

**一、可验证奖励（verifiable reward）正在临床场景落地。** 本周三篇（FoG 的证据覆盖奖励、本体 CUI 重叠 GRPO、MedCBR 的熵控 rubric）共同指向一个转向：医学对齐不再满足于人类偏好标注，而是寻找"外部指定、模型不在环"的软验证器。值得追问的白空间是——**mNGS 病原判读能否构造同款软验证器？** 例如用参考数据库比对结果、培养药敏报告、专家复核结论做成分级奖励，训练"病原报告生成"的 RLVR 流水线，目前尚无人做。

**二、"能力边界采样"可能取代难度采样。** MedCBR 用经验通过率定位模型能力边界、构造共享前缀分叉的偏好对，这与医学考试中"错在临界题"的规律吻合。可探索的方向：用考题集（MedQA/UMLS-200）的通过率曲线动态挑选训练批次，把算力集中在梯度最有信息量的区间——对小模型（3-8B）尤其可能高效。

**三、DNA FM 的"效用审计"产业缺口。** "What DNA FMs Learn" 与 "Evo 2 FP8" 从内容和基础设施两侧揭示同一问题：行业缺乏对基因组基础模型的标准化体检——包括 composition 对照、线性可恢复性分解、跨硬件数值一致性。**设想一个 genomic-FM model card 基准**（k-mer baseline + 数值位精确测试 + 下游迁移矩阵），类似 LLM 的 HELM；若与临床变异解读场景结合（如 BRCA1 AUROC 这类指标），会成为极佳的空白方向。

**四、"自我克制"应成为临床智能体的一级指标。** Planner-Executor 的 defer-to-doctor 与 Nature Cancer 的 human verification 都在强调"何时不回答"。建议构建统一的 **abstention-aware 临床智能体评测**：把转诊准确率、拒绝质量、确认后增益（human-in-the-loop Δ）并列报告，而不是只报准确率——这会直接影响监管（MDR/AI Act）材料的组织方式。

**五、检索策略优化建议。** ① 方向 A 的"mNGS+LLM"在 PubMed 近两月几乎无直接命中（多为纯 mNGS 临床研究），建议下一版查询加入 "unclassified reads / pathogen interpretation / LLM-based reporting" 语义，并把 medRxiv/bioRxiv 的 bioRxiv 内容检索权重上调；② 方向 C 需要 arXiv 兜底（PubMed 命中多为评测而非对齐训练），可固定 `RLHF|DPO|preference optimization` + `clinical|medical` 的 arXiv API 常驻查询；③ OpenAlex 的 `search` 参数对 A/C 方向噪声极大（本周命中率 <15%），建议降级为"仅补 DOI/摘要"，或改用其 `filter=title_and_abstract.search` 收紧。

**一句话总结：** 临床智能体正在从"会答"进化到"答得有证据、该拒就拒"，而基因组基础模型开始进入"自证清白"的效用审计阶段——两条线索在"可验证性"上汇合。
