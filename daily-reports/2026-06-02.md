## B. 临床 Agent + RAG/知识图谱

### 🔥 [B1] GRASP: Gated Regression-Aware Skill Proposer for Self-Improving LLM Agents
- **链接**: [arXiv:2605.29668](https://arxiv.org/abs/2605.29668) | 2026-05-28
- **作者**: Johannes Moll 等 (TU Munich / Microsoft Healthcare)
- **核心贡献**: 提出 GRASP 框架，通过带回归预算的门控机制，让 LLM Agent 在结构化环境（FHIR EHR）中自我改进。在 MedAgentBench 上将 gpt-oss-120b 从 40.6% 提升至 88.8%，超越最强基线 21 个百分点.
- **方法**: 故障驱动的技能提案 + 回归感知选择（硬回归预算约束）+ 对比修订
- **关键发现**: 无验证的技能编写不比不用技能好；强模型写入技能可不对称迁移至弱模型执行
- **代码**: [github.com/jomoll/GRASP](https://github.com/jomoll/GRASP)

### 🔥 [B2] MedCase-Structured: A Text-to-FHIR Dataset for Benchmarking Diagnostic Reasoning

- **作者**: Valentina Bui Muti 等 | **Accepted to ICML 2026 Structured Data for Health Workshop**
- **核心贡献**: 构建多阶段 LLM Pipeline 将临床自由文本转换为 HL7 FHIR R4 Bundles，生成 1,408 例结构化病例用于评估诊断推理能力
- **关键发现**: LLM 在结构化 FHIR 输入上的诊断准确率显著低于纯文本输入，凸显部署对齐基准的重要性
