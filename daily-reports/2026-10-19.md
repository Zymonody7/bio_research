## 🧠 跨界发现

**1. MCP 正在成为临床/生物 agent 的工具层标准接口。** 本日两篇独立论文(方向 B 的 EHR+KG 真实世界证据框架、方向 X 的 PMxAgent 药代平台)都不约而同地采用 Model Context Protocol 把 LLM 接到结构化数据与领域工具上，并以 OpenAPI 规范自动生成 agent 可调用工具。若成立，临床 agent 的瓶颈将从『模型能力』迁移到『工具/数据源的 MCP 化程度」。

**2. 对齐研究的『部署协议』正在成为被忽视的第二变量。** 方向 C 的部署协议论文给出硬证据：安全残余风险由基座模型 × 部署协议共同决定，handoff(交接给人)开关就能让违规率差异数倍。这提示 RLHF/DPO 医学对齐论文若只报离线 benchmark 而不报部署协议，其结论无法迁移到真实临床。

**3. 技能库(skill library) vs 更大检索器：纵向病历合成的新答案。** 方向 B 的骨髓瘤 agentic 论文显示，索引式临床技能库驱动的推理达到专家级一致性并系统超越各种 RAG 变体。这把『RAG 调优』的注意力转向『可复用临床技能的编目与调度」。

**4. 基因组 FM 的价值正从『预测精度』转向『可迁移先验』。** 方向 D 的 GLM-Prior 把 DNA 语言模型定位为『序列→TF-靶互对』的先验生成器去补 GRN 推断，BFPSM 用多语言模型嵌入解同义突变致病性。共性：语言模型作为先验/表征提供者，而非端到端预测器。

**5. 治理(governance)从边缘议题走向范式核心。** 方向 F 的 Science Bulletin 与 RADAR 的『引用校验+弃答』共同指向：可追溯/可审计/可弃答正在成为临床 agentic 系统的一等设计目标，而非事后补丁。
