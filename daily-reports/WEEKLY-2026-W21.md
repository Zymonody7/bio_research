### 趋势一：Agent 从"工具增强"走向"自我进化与层级协作"

本周 Agent 论文的最显著转变——不再满足于"给 LLM 配几个工具"，而是追问更深层的问题：

- **自进化 (STELLA, 05-20):** Agent 自主发现、测试、集成新工具。对临床 Agent 启示：不应只调用固定 RAG/KG，而应根据病例独特性自主搜索新文献、调用新模型。
- **层级安全 (TAO, 05-20):** 三级 Agent 监督框架（护士→医生→专科医生），级联错误吸收可达 24%。安全从"单模型能力"升级为"结构性属性"。
- **动态协作 (DynamiCare, 05-20):** 根据每轮新信息动态调整专科医生团队组成。
- **三方协作 (AI Co-Clinician, 05-19):** AI 作为医生-患者之外的"第三方协作者"而非替代者。

**共同信号：** Agent 架构的关键不再是工具数量，而是**模块间的信息流质量和边界的合理划分**。CARE 的三阶段分解（实体提议→像素证据→扎根推理）比朴素多 Agent 更有效，因为它遵循临床工作流的认知结构。
