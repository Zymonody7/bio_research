## 方向 A：mNGS + AI 病原检测

**A1 🔥 Ecological heterogeneity beneath the pneumonia label: pathogen community gradients in clinical targeted sequencing of bronchoalveolar lavage fluid**
- 作者：Ying Li, Haoyuan Yin, Xiangyang Lyu, Chao Liu, Xue Li | *Frontiers in Cellular Infection Microbiology*, 2026-11-10
- DOI: `10.3389/fcimb.2026.1954468`
- 要点：1,247 例 BALF **tNGS** 样本（2025-12~2026-07），RPM 归一化 + 文库大小残差化；PERMANOVA/PERMDISP 验证群落差异，PCA 提取生态轴 + 文献定义的 dysbiosis 指数做收敛验证，指示种分析（IdentVal）找出驱动差异的病原；建立 **PC1×PC2 双轴象限框架**用于临床转化。核心发现：肺炎二分标签掩盖了病原群落的生态异质性。
- 为什么收：A 方向今日最实证的一篇——"诊断标签 ≠ 生态分层"直接对应你 mNGS 判读中**阳性/定植/污染混淆**的痛点；双轴象限是可直接借鉴的**判读分层输出格式**（比"检出/未检出"多一维临床语义）。

**A2 📎 Benchmarking nanopore-based strategies for antimicrobial resistance prediction**
- 作者：Natalie Ring, Alison S. Low, Rhodri Evans, Marianne Keith, Gavin K. Paterson, David L. Gally | *Microbial Genomics*, 2026-11-03
- DOI: `10.1099/mgen.0.001885`
- 要点：真实 nanopore 数据 × 201 样本 × 27 菌种配对 AST 表型，系统评测 **basecalling 模式 / 数据量 / 组装策略**三个变量对 in silico AMR 预测的影响，横向对比 8 个 AMR 预测工具 × 7 个 AMR 数据库。结论：basecalling 精度模式影响不显著，但**组装策略与数据量显著影响**；ResFinder 系（ResFinder/ABRicate）平衡准确率最佳（0.80±0.02），DeepARG 表现分化。
- 为什么收：📎 **mNGS 上游管线的对照基准**——"工具差异 < 管线变量差异"这一结论提醒：AI 判读模型的评测必须把数据量/组装方式当作受控变量，否则增益可能是管线假象。

## 方向 B：Clinical Agent + RAG / Knowledge Graph

**B1 🔥 LongCAF: A longitudinal context-constructive agentic framework for LLM-supported hypertension self-management**
- 作者：Yaoqian Sun, Longyun Tao, Han Yu, Yijie Wang, Kexin Zheng, Han Chen | *Journal of Biomedical Informatics*, 2026-11
- DOI: `10.1016/j.jbi.2026.105108`
- 要点：针对患者表达碎片化/上下文不完整/意图漂移三个真实痛点，构建**纵向记忆 + 交互协调 + 主动沟通 + 安全升级（safety escalation）**四模块的上下文建构型 agent 框架；把一次性问答范式升级为跨会话的上下文持续建构，明确设计了何时该转人工/就医的升级通道。
- 为什么收：**B 方向今日最强**——"安全升级通道"是临床 agent 从 demo 走向可用的关键机制，与你报告证据链中的"何时该说不知道/该转诊"直接同构；纵向记忆的上下文建构方法可移植到慢病随访场景。

**B2 🔥 A multi-agent large language model (LLM) platform for structured medical anamnesis in outpatient care（Symptio）**
- 作者：Elena Zaitseva, Simon Ochotnicky, Miriam Fandakova, Vitaly Levashenko, Jan Rabcan | *Frontiers in Digital Health*, 2026
- DOI: `10.3389/fdgth.2026.1882397`
- 要点：把 **SOCRATES / Review of Systems / SAMPLE** 三套问诊框架形式化为机器可解释约束，多 agent 平台在预问诊阶段结构化采集病史，human-in-the-loop 工作流。100 个模拟门诊场景：三框架全结构一致率 87%（SOCRATES 96% / ROS 88% / SAMPLE 93%），F1 98.79%；58 处字段级差异含 28 处中等严重度错误 → **全部输出仍需医师复核**。
- 为什么收：**"临床框架 = 约束规范"模式**——问诊套路不是提示词而是可校验的结构约束，这套"结构一致率 + 字段级严重度分级"评测法可直接搬到你的临床报告生成评测。

**B3 🔥 An Agentic LLM Framework for Autonomous Surgical Continuum Monitoring: ReAct-Driven Tool-Use Agents**
- 作者：Pylarinou C, Gortzis L, Leivaditis V, Liolis E, Antzoulas A, Papadoulas S | *Bioengineering*, 2026-06-15
- DOI: `10.3390/bioengineering13060686`
- 要点：用 **6 个 ReAct tool-use agent** 取代硬编码规则 MAS，覆盖术前风险分层→术中监护→术后 ICU/病房/远程康复全 continuum；每 agent 有 ReAct loop 签名 + 10 函数临床工具注册表 + **置信度门控 HITL 升级**；Reflexion 自纠错 + LLM 协调主管（Coordination Supervisor）替代规则优先级队列，嵌入 DETER Digital Twin 状态引擎 S(t)。
- 为什么收：**"置信度门控 + 强制 HITL"是 agent 自主性的安全阀设计**——与 B1 的 safety escalation、你 doctor-facing UI 的信任校准是同一问题的三种解法；跨 agent 资源竞争用 LLM 协调而非规则队列，是多 agent 临床编排的新样本。

## 方向 C：RLHF 医学对齐

**C1 🔥 Guardrail Erosion in Domain Fine-Tuned Large Language Models: A Paired Audit of Knowledge-Centric Abstention in Biomedical LLMs**
- 作者：Stephen Peng, Vineet Jagadeesan Nair, Noah Broestl, Anne Friederike Kleppe, Steven Mills, Adi Zolotov | *arXiv:2611.08780*, 2026
- 要点：**配对审计设计**（25 个生物医学微调模型 vs 11 个配对 base checkpoint），在 MedAbstain + ClinDet-Bench 上量化微调对**知识性弃答（knowledge-centric abstention）**的影响——区别于以往只看 value-centric refusal。关键数字：base 模型的恰当弃答率中位数已仅 8.3%，微调后进一步下降；跨架构/数据配方/微调方法的大规模证据。
- 为什么收：C 方向今日最强——**"对齐"不只管有害内容，还管'不知道时闭嘴'**；医学场景里弃答能力退化 = 幻诊风险上升，这对你的医学模型选型/微调监控是可直接落地的审计协议（配对 diff 而非绝对分数）。

**C2 🔥 Scaling medical imaging report generation with multimodal reinforcement learning（UNIRG）**
- 作者：Qianchu Liu, Sheng Zhang, Guanghui Qin, Yu Gu, Ying Jin, Sam Preston | *Nature Communications*, 2026
- DOI: `10.1038/s41467-026-78767-4`
- 要点：影像报告生成从 SFT 转向 **RL（GRPO）直接优化临床质量指标**：复合奖励 = 词面 + 语义 + 临床错误惩罚；UNIRG-CXR（8B VLM）在 MIMIC-CXR/CheXpert Plus/ReXGradient-160k/IU-Xray 四集训练，ReXrank 基准超越先前模型，RadCliQ 主指标 + 放射科医师专家验证 + 外部私有数据集泛化。
- 为什么收：**"临床错误惩罚进奖励函数"是 RLHF 医学对齐最实的落地**——SFT 过拟合表面模式的诊断 + 复合临床奖励的处方，正是 C×F 交点；报告生成与你的证据链报告任务同域。

**C3 🔥 Safe Reinforcement Learning for Multi-Turn Clinical Agents: When Dense Rewards Beat Outcome Rewards**
- 作者：Brendan P. Murphy, Agustina D. Saenz | *arXiv:2611.12728*, 2026
- 要点：三个受控环境（用药续方分诊 / 急性诊断检查 / 剂量滴定），各有隐藏临床状态、查询成本、精确自适应 oracle 与确定性结果验证器。发现**仅结果奖励的 GRPO 常提升总奖励却产生坏过程**：过早承诺（premature commitment）、一问塌缩（one-question collapse）、罕见高风险病例失败；给"降低不确定性的问题"分配**密集信用（dense credit）**能提升 held-out 价值。
- 为什么收：**C×B 交点、本轮方法论最锋利**——"总奖励涨了 ≠ 临床过程对了"是多轮临床 agent 强化学习的机制级警告；密集信用设计（为'问对问题'而非'答对'奖励）可直接移植到你的临床 agent 训练/评测。

## 方向 D：Genomic Foundation Models

**D1 🔥 LUNA-FM: a subword foundation model for long non-coding RNAs for functional inference**
- 作者：Naima Vahab, Estrid He, Tabinda Sarwar, Sonika Tyagi | *RNA Biology*, 2026-11-13
- DOI: `10.1080/15476286.2026.2763191`
- 要点：约 2,800 万条冗余过滤 ncRNA 上预训练的 RNA 基础模型，核心创新是**子词（subword）分词 + 长上下文 Transformer**，系统评测分词策略与词表大小在序列压缩率 / 表示粒度 / 计算效率 / 下游性能四者间的权衡；针对单核苷酸分词导致长 lncRNA 序列过长、成本高的具体问题。
- 为什么收：**"分词是基因组 FM 的被低估杠杆"**——与既往 EvoLen/MergeDNA 的 DNA 分词信号合流，LUNA-FM 把它系统化到 RNA/lncRNA 域；四维权衡评测框架可复用于任何核酸 FM 的分词消融。

**D2 📎 Evo2VED: a database of DNA large language model-derived scores for variant interpretation**
- 作者：Rui Zhu, Xiaopu Zhou, Ivy Liang, Marla Mendes, Worrawat Engchuan, Nickie Safarian | *Nucleic Acids Research*, 2026-11-13
- DOI: `10.1093/nar/gkag1076`
- 要点：Evo2（7B/40B）衍生变异效应分数的预计算资源：**648 万** gnomAD 变异 × 3 种打分方案，整合功能/约束/等位基因年龄/疾病注释 + UK Biobank/FinnGen/MVP 三大 GWAS；三模块（变异级/区域集/性状级）查询与可视化；用 MPRA、mQTL、fine-mapping、临床注释评估 Evo2 分数**超越保守性与调控注释的增量价值**；高血压/抑郁案例演示。
- 为什么收：📎 **FM 分数正在变成临床注释层**——"DNA LLM 打分 → 生物库 GWAS → 精细定位"的证据链是 D 方向落地形态的样板；其"增量价值评估"方法（对已有注释的边际贡献）是评判任何 FM 声明的标准答案模板。

**D3 🔥 Assessing the Capacity of Genomic Language Models to Generate Informative Embeddings of Viral Genome Fragments**
- 作者：Alexandr Kladchenko, Alexander Manolov, N. S. Popov | *bioRxiv*, 2026-11-09
- DOI: `10.64898/2026.11.09.765411`
- 要点：系统评估 4 个 gLM（**DNABERT-2、DNABERT-S、ViraLM、Evo2-7B**）对短病毒基因组片段的分类学嵌入能力，基准数据集基于 ICTV Virus Metadata Resource，与传统 **k-mer profile / MinHash sketch** 在聚类（ARI）与近邻（precision@k、CROSS precision@k）指标下同协议对比。发现：3/4 gLM 优于 4-mer；**中间层最佳**；k-mer 稳定压过 MinHash；在参考集外的两个病毒目（egoviruses/mriyaviruses）上 DNABERT-S 最稳。
- 为什么收：**D×A 交点、本轮跨界价值最高**——"FM vs k-mer"的同协议对照给出冷静结论（gLM 有优势但非碾压、中间层才是好读出），直接可用于你 mNGS 流程里"要不要上 FM 做病原分型"的决策；外推测试（参考集外病毒目）设计尤其值得抄。

## 方向 F：Multimodal Clinical Agent

**F1 🔥 End-to-End PET/CT Interpretation and Quantification with an LLM-Orchestrated AI Agent: A Real-World Pilot Study**
- 作者：Hongyoon Choi, Sungwoo Bae, Kwon Joong Na | *Journal of Nuclear Medicine*, 2026
- DOI: `10.2967/jnumed.126.272362`
- 要点：**推理型文本 LLM 作为编排者**：从原始 DICOM 自动选序列 → 协调配准/SUV 转换 → 调分割与检出工具 → 生成 MIP → 调视觉 LLM 解读 → 合成结构化报告草稿。170 例肺癌分期 [18F]FDG PET/CT 回顾性评估，临床报告为参考标准。
- 为什么收：F 方向今日最完整的真实世界证据——**"文本 LLM 编排 + 视觉 LLM 末端"的双层 agent 架构**从 raw 数据到报告全打通，是多模态临床 agent 从 benchmark走向 workflow 的参考实现（与你 PET/影像报告链直接相关）。

**F2 🔥 PROVE: Proof-guided Regime-aware Operator Verification for Hallucination Detection in Medical VQA**
- 作者：Keyang Zhou, Siyi Li, Zhongnan Shi, Qichao Ying, Wei Tang, Zhenxing Qian | *ACM Multimedia (ACM MM)*, 2026
- DOI: `10.1145/3767308.3835815`
- 要点：黑盒幻觉检测器：按问题所需的**视觉证据结构**分三个验证 regime，每 regime 激活 5 个互补算子的特定子集，轻量注意力按题调算子权重——纠正"所有问题用同一验证策略"导致的过度自信错误漏检与过度验证误报。
- 为什么收：**"验证策略随证据类型路由"**——与 C1 的弃答审计、F3 的一致性评测共同指向同一主题：可靠性机制不能一刀切；算子×regime 设计可嫁接到你报告证据链的引用校验。

**F3 🔥 Evaluating Cross-Signal Coherence in Mammography Vision-Language Models**
- 作者：Rebeca Nam, Chase M. Fensore, Christian Allison Fauria-Robinson, Judy Gichoya, Joyce C. Ho | *arXiv:2611.12574*, 2026
- 要点：评测 VLM **答案-置信度-解释三信号一致性**（乳腺密度 + BI-RADS，两个数据集）：受控扰动问题措辞/选项顺序/图像。发现：图像被替换后置信度**不下降**；打乱选项会改变多数模型答案；存在**自述理由与最终答案自相矛盾**的案例——准确率完全无法捕捉这种"不可信"。
- 为什么收：F 方向今日最尖锐的负结果——**"准确率之外的第三类失败"**（内部不一致）直接支持你 doctor-facing 输出必须带自洽性门控；扰动协议（选项乱序/换图）是零训练的 VLM 可靠性体检套餐。

## 🧠 前沿洞察与头脑风暴

**1）"过程正确性"成为医学 agent 对齐的共同主题。** C3（结果奖励产生坏过程：过早承诺/一问塌缩）与昨日 C1 PROSE（过程奖励修复 test-time RL 塌缩）构成连续证据链：医学场景里**答案层面的奖励会系统性奖励错误的行为路径**。叠加 C1 Guardrail Erosion（微调使恰当弃答率从本就只有 8.3% 的中位数继续下滑），一个新命题浮出水面——医学对齐的三支柱正在从"安全拒绝"扩展到"知识性弃答"与"过程信用分配"。建议把"弃答率 + 过程指标"纳入你所有医学模型评测的常设面板。

**2）FM 与经典基线的冷静期。** D3 给出同协议对照：gLM 优于 k-mer 但非碾压、中间层才是最佳读出、参考集外泛化时 k-mer+JSD 仍顽强。配合 D2 Evo2VED（FM 分数成为生物库级注释层），说明行业分化为两派：**造更大的模型** vs **把已有 FM 变成可消费的证据服务**。对你的 mNGS 工作，白空间在中间地带：gLM 嵌入作为病原报告 RAG 的检索键（"检出序列 → 相似病原证据簇"），目前无人做。
