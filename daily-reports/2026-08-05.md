## 🧠 前沿洞察与头脑风暴

### 跨界信号 (Cross-Signals)

**1. Agent × PLM 融合加速**
AgentPLM（#9）和 MEDVISTAGYM（#15）分别从蛋白质和医学影像两个方向展示了 Agent 能力与基础模型融合的趋势。这不是简单的 tool-use 包装，而是将推理、规划、反馈循环深度嵌入模型架构。下一步可能是 **Agentic mNGS**——让 mNGS 分析流水线具备自主推理和自我纠错能力。

**2. 后训练（Post-Training）成为基因组 FM 的关键杠杆**
论文 #12 直接证明后训练对生物学推理模型的影响远超预训练。这意味着基因组基础模型的竞争将从"谁的预训练数据更多"转向"谁的 SFT/RLHF 方案更优"。对于我们的研究，这是一个明确的信号：**投资后训练 pipeline 比投资预训练数据更有杠杆效应**。

**3. 偏好学习渗透抗体设计**
论文 #10 将 RLHF 的核心思想（偏好学习）应用于抗体表达排名。这暗示了一个更大的趋势：**RLHF 框架正在从 NLP 溢出到蛋白质工程**。DPO、GRPO 等对齐技术可能很快成为抗体优化的标准工具。

### 新兴概念 (Emerging Concepts)

- **Differential Reasoning for Clinical Agents**（#5）：不是简单地给出诊断，而是系统性地排除不可能的诊断。这种推理模式对 mNGS 病原体鉴定同样适用——从阳性信号中排除污染和共生菌。
- **Neurosymbolic Medical Agents**（#16）：将符号推理（规则、知识图谱）与神经网络结合，在可解释性和性能之间取得平衡。这可能是临床 Agent 走向监管合规的关键路径。
- **Learnable Tokenization for Genomic Data**（#13）：突破固定 k-mer 分词，让模型学习最优的基因组序列表示。这可能是下一代基因组 FM 的核心创新点。

### 白色空间 (White Spaces)

1. **mNGS × Agent 自动化**：目前 mNGS 分析仍以手动/半自动流水线为主，缺乏具备推理能力的端到端 Agent。这是一个巨大的应用空白。
2. **基因组 FM 的偏好对齐**：将 RLHF/DPO 应用于基因组基础模型的对齐，使其输出更符合临床需求——目前几乎没有相关工作。
3. **多模态 mNGS Agent**：整合测序数据、临床表型、影像数据的多模态诊断 Agent，目前处于早期探索阶段。
