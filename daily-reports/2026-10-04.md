## Direction A — mNGS + AI 病原检测（3 篇）

### 1. 🔥🔥 PathoBERT: A Hybrid Attention-Based Genomic Language Model for Read-Level Bacterial Pathogenicity Prediction
- **作者**: Salem A. El-aarag, Mario Flores, Mohamed E. Hasan, Alaa E. Hemeida, Mahmoud ElHefnawi
- **来源**: bioRxiv（预印本，2026-09-29）· DOI: 10.64898/2026.09.27.754806
- **摘要要点**: LoRA 适配的 DNABERT 编码器 + 卷积特征 + MCBAM/MSCA 注意力的混合框架，直接在测序 read 层面预测细菌致病性。接近完全的链不变性，模拟测序错误下鲁棒；150 bp 片段表现最佳，超过 DeePaC；通过 PathFrac（read 级多数投票聚合）实现基因组级完美分离致病/非致病基因组，优于 DeePaC 与 PathogenFinder2。
- **为什么值得读**: 这是「基因组语言模型 → mNGS 病原检测」的直接桥梁：把 DNA LM 从抽象 benchmark 拉到真实 NGS read 工作流，且显式评估了测序噪声鲁棒性——这正是 mNGS 临床落地的核心痛点。**同时是 Direction D 的跨界信号**。
- **链接**: https://www.biorxiv.org/content/biorxiv/early/2026/09/29/2026.09.27.754806.full.pdf

### 2. 📎 Comparative assessment of large language models for microbial phenotype assignment
- **作者**: Philipp C. Münch, Nasim Safaei, René Mreches, ... Curtis Huttenhower, Alice Carolyn McHardy
- **来源**: Genome Biology（2026-07-23）· DOI: 10.1186/s13059-026-04207-7
- **摘要要点**: 系统评估最多 57 个 LLM（含 Claude Sonnet 4、GPT-5 系列）对微生物物种的结构化表型注释能力。多数物种可准确注释，但模型与性状间差异大、无单一模型全面占优；模型自报置信度与准确率正相关，可用于筛选高置信推断。
- **为什么值得读**: 通用 LLM 作为「微生物学知识库」的可靠性基线——对判断何时该用 LLM 直接回答、何时必须接检索/实验验证，提供了量化依据。📌 方法参考。
- **链接**: https://link.springer.com/content/pdf/10.1186/s13059-026-04207-7.pdf

### 3. 📖 Application value and challenges associated with plasma cell-free DNA metagenomic sequencing technology in the diagnosis of infections in patients with hematological disorders
- **作者**: Xu C, Liu T, Zhang X, Feng S
- **来源**: Blood Science（2026）· DOI: 10.1097/BS9.0000000000000304
- **摘要要点**: 血液病患者免疫功能低下、感染谱复杂，常规微生物检测受限。综述血浆 cfDNA mNGS 在发热性中性粒细胞减少、血流感染、局灶感染及苛养/罕见病原中的应用；强调其克服抗生素干扰、实现早期检测的价值；也坦承局灶感染敏感性低于靶点取样、难以从 cfDNA 直接预测 AMR 的瓶颈；介绍中国通过本地化模式、降本与临床解读模型推动的规模化落地路径。
- **为什么值得读**: 给出了 cfDNA mNGS 临床场景的「适应证-局限」全景图；「AMR 预测难」这一短板恰好是 AI 需要切入的空白。📖 综述。
- **链接**: https://doi.org/10.1097/BS9.0000000000000304

## Direction B — 临床 Agent + RAG/知识图谱（3 篇）

### 4. 🔥🔥 Blind spots in AI-assisted healthcare evidence search: multiplatform evaluation of clinical retrieval gaps and risk-of-bias
- **作者**: Ahmed N. Farrag, Ahmed S. A. Soliman, ... Masoud Rouhizadeh
- **来源**: npj Digital Medicine（2026-09-29）· DOI: 10.1038/s41746-026-03277-y
- **摘要要点**: 用前瞻性构建、非公开的金标准语料（规避 benchmark 污染），评估 Consensus、Ai2 Paper Finder、ChatGPT、Gemini、Claude 五个 RAG-LLM 证据检索平台 × 15 种查询表述。单查询表述级中位召回仅 7.2%–42.2%；最大证据类别的单查询零召回概率高达 47%–80%；12.0% 的证据从未被任何平台检出，会议文献「从未被检出率」显著高于期刊论文（38.9% vs 4.6%）。
- **为什么值得读**: 给临床 RAG 系统敲响系统性警钟——检索偏差与可见性盲区是结构性的，部署前必须做领域内评测。是 Direction B 的关键反面证据。
- **链接**: https://www.nature.com/articles/s41746-026-03277-y

### 5. 🔥🔥 Ascent: An Agentic System over the Model Context Protocol for Real-World Clinical Data Analysis
- **作者**: Angelo Ziletti, Leonardo D'Ambrosi, Melanie Tuchardt, Tim Kondziella
- **来源**: arXiv（2026-09-21）· DOI: 10.48550/arxiv.2609.24620
- **摘要要点**: 将医学编码、问答、队列分析统一暴露为 Model Context Protocol（MCP）工具面，支持标准化与原生 schema。提出 EpiTrap 数据集，检验系统是否规避已知的药物流行病学错误（人群、分母、时间窗等隐式选择）。有能力的模型驱动下，agent 相对固定 pipeline 在原生/标准化 schema 上分别平均提升 27/20 个百分点，代价是更多工具调用与更长运行时间。
- **为什么值得读**: MCP 作为临床数据 agent 的标准化接口正在成形；EpiTrap 用「已知流行病学陷阱」做对抗式评测的思路值得借鉴。
- **链接**: https://arxiv.org/pdf/2609.24620

### 6. 🔥 Agentic memory-augmented retrieval and evidence grounding for medical question-answering tasks
- **作者**: Jia S, Bit S, Jasodanand VH, Liu Y, Kolachalama VB
- **来源**: International Journal of Medical Informatics（2026）· DOI: 10.1016/j.ijmedinf.2026.106339
- **摘要要点**: 开源 tool-using agent 系统，集成文档检索、重排、证据锚定与诊断生成；轻量 RAG pipeline 配合 cache-and-prune 记忆库突破标准 LLM 上下文限制，自动调用专用工具、无需手工模板。USMLE Step 1 达 82.98%、Step 2 达 86.24%，超过 GPT-4 同项（80.67%/81.67%）。
- **为什么值得读**: 记忆库 + 证据锚定 agent 在标准化医学考试上的复现结果，可作为自建临床 agent 的强基线配置。
- **链接**: https://doi.org/10.1016/j.ijmedinf.2026.106339

## Direction C — RLHF 医疗对齐（3 篇）

### 7. 🔥🔥 When Rubrics Fail: Hallucinations Reveal Blind Spots in Medical AI Evaluation
- **作者**: Griffin Farrow, Lily Sijia Li, ... Philip H. S. Torr, William Bolton, Fabio Fehr
- **来源**: arXiv（2026-09-11）· DOI: 10.48550/arxiv.2609.12718
- **摘要要点**: Rubric 评分已成为医疗 LLM 评估的主流方法，但其能否反映临床相关错误存疑。作者构建医疗幻觉分类法 + 临床医生验证的错误注入管线，在 HealthBench、HealthBench Professional、LiveMedBench 上生成配对的正确/错误注入回答：临床相关的幻觉经常被 rubric 漏检、分数不变。Rubric 仅在显式检查事实时有效；检索式事实核查可部分找回 rubric 盲区错误。
- **为什么值得读**: 直击「用 rubric 做 RLHF 奖励/评估」的根基性风险——奖励模型看不见的错误，对齐过程也学不到。对做医疗 reward model 的人是必读反例。
- **链接**: https://arxiv.org/pdf/2609.12718

### 8. 🔥🔥 Scaling Clinical Judgment to Evaluate Medical AI（PrecepTron + GRAND-ROUNDS）
- **作者**: Thomas A. Buckley, Zahir Kanjee, Peter G. Brodeur, ... Jason A. Freed
- **来源**: arXiv（2026-09-11）· DOI: 10.48550/arxiv.2609.12822
- **摘要要点**: 盲法医生评估是临床推理评估金标准但难以规模化。提出 PrecepTron——用 LoRA 在 32B 模型上以少量医生标注微调出的「医生级」评估器；发布 GRAND-ROUNDS 基准（9,217 条评分回答、160 名医生、7 项研究）。前沿 LLM 的 LLM-as-judge 与医生、彼此之间常不一致；PrecepTron 少量病例微调后即可跨任务达到医生级一致性，并复现了 JAMA/Science/Nature Medicine 五项研究的结论。
- **为什么值得读**: 「评估规模化」与「对齐信号规模化」是同一问题的两面——可扩展的医生级 judge 直接决定 RLHF/RLAIF 医疗对齐的天花板。
- **链接**: https://arxiv.org/pdf/2609.12822

### 9. 🔥 RadHiera: Semantic Hierarchical Reinforcement Learning for Medical Report Generation

## Direction D — 基因组基础模型（3 篇）

### 10. 🔥🔥 Mendel: a foundation model of human genetic variation prioritizes regulatory variants and improves gene expression prediction
- **作者**: Arham Salman, Haonan Feng, Peng Wei, Ryan Sun, Lang Wu, Wei Pan, Chong Wu
- **来源**: bioRxiv（2026-09-30）· DOI: 10.64898/2026.09.28.755183
- **摘要要点**: 现有 DNA 基础模型的训练目标被「所有个体共享的保守背景」主导，而人类遗传变异集中在稀疏变异位点。Mendel 从头在人类全基因组上以**变异中心目标（variant-centric objective）**预训练，监督聚焦于参考比对序列背景中的等位基因事件。留出个体上 SNV 等位基因预测准确率 0.984 vs Evo 2 的 0.311；其残差难度选择性富集于 cis-eQTL 变异，精细定位因果变异 AUROC 0.731（Evo 2 残差近乎随机）；作为 cis-expression 先验可在全部 50 个 GTEx 组织中改进表达预测。
- **为什么值得读**: 今日最佳候选。指出了 DNA FM 预训练目标的结构性缺陷并给出干净的解决方案——「变异中心监督」可能成为下一代基因组 FM 的标配设计。
- **链接**: https://www.biorxiv.org/content/biorxiv/early/2026/09/30/2026.09.28.755183.full.pdf

### 11. 🔥🔥 Evo 2 as a classification machine: evidence from in-context learning and mechanistic interpretability
- **作者**: Lorenzo Bertolini, Fabiola Curion, Mauro Petrillo, ... Sergio Consoli, Mario Ceresa
- **来源**: bioRxiv（2026-09-30）· DOI: 10.64898/2026.09.30.755330
- **摘要要点**: 系统测绘 Evo 2 在 5 个二分类任务（生物/人工序列）上的 in-context learning 能力：短天然序列稳健（miRNA F1=0.902、毒素 0.785），随长度退化、千碱基尺度崩溃；**7B 模型系统性优于 40B**（scaling 无收益）；perplexity 与下游准确率关联很差。机制可解释性（logit-lens、Jacobian Scope）给出调和解释：存在预测-泛化权衡，模型可能追踪 prompt 结构而非信号内容。
- **为什么值得读**: 对「基因组 FM 的涌现能力」祛魅的高质量负结果——perplexity 不能当代理指标、参数规模不等于下游能力，直接影响评测与选型。
- **链接**: https://www.biorxiv.org/content/biorxiv/early/2026/09/30/2026.09.30.755330.full.pdf

### 12. 🔥🔥 PlantCAD2: A DNA foundation model for interpreting genomes across flowering plants
- **作者**: Zhai J, Gokaslan A, Hsu SK, Chen SP, Liu ZY, ...（多机构合作）
- **来源**: Cell Genomics（2026）· DOI: 10.1016/j.xgen.2026.101329
- **摘要要点**: 扩展上下文、植物特异、单核苷酸分辨率的 DNA 语言模型，在 65 个被子植物基因组上预训练并配套公开 benchmark。零样本测试中 676M 参数的 PlantCAD2 在 12 项任务中的 10 项超过 7B 的 Evo 2；PEFT 微调后在 7 项跨物种任务（染色质可及、基因表达、蛋白翻译）上超过 1B 的 AgroNT；8,192 bp 上下文使玉米等大基因组的可及染色质预测 AUPRC 从 0.587 升至 0.711，证明长程上下文对远端调控建模的关键作用。
- **为什么值得读**: 「小而专 + 长上下文」击败「大而通用」的又一实证；Domain FM（物种群特异）路线得到 Cell Genomics 级别背书。
- **链接**: https://doi.org/10.1016/j.xgen.2026.101329

## Direction F — 多模态临床 Agent（3 篇）

### 13. 🔥🔥 StrokeAgent: An auditable multimodal agentic system for sequential decision-making across the acute stroke pathway
- **作者**: Ke Yang, Zhijie Bao, Lusha Tong, ... Xueyu Mao, Jin Zheng
- **来源**: medRxiv（2026-10-01）· DOI: 10.64898/2026.09.24.26363786
- **摘要要点**: 面向急性缺血性卒中全流程的多模态 agent：整合临床记录、检验、原始 ECG 波形与多模态 CT 源影像，支持急诊分诊、溶栓决策、再灌注方案规划；随信息流在每个决策点形成并更新建议，每条建议锚定可审计的证据链。100 例富集复杂再灌注场景的评估中，与专家终审决策一致率 86%，在信息内容与时点匹配条件下超过无工具 LLM 均值 13 个百分点、超过 13 名住院医/主治神经科医生均值 17 个百分点；全流程一致率 76%，领先幅度更大。
- **为什么值得读**: 「多模态 + 时间对齐 + 可审计证据链」的临床 agent 工程范式在时间压力最大的急救场景拿到阳性结果——审计链设计是亮点。
- **链接**: https://www.medrxiv.org/content/medrxiv/early/2026/10/01/2026.09.24.26363786.full.pdf

### 14. 🔥 Stereotactic radiosurgery plan optimization with a human-in-the-loop reasoning large language model agent
- **作者**: Humza Nusrat, Luke Francisco, Bing Luo, ... Mohammad Ghassemi
- **来源**: Scientific Reports（2026-09-30）· DOI: 10.1038/s41598-026-73885-x
- **摘要要点**: 在本地部署的 SAGE agent 中对比推理优化模型（QwQ-32B）与通用模型（Llama 3.1-70B）自然语言调整 Eclipse 优化目标优先级的能力。41 例单靶点脑转移立体定向放射外科回顾性病例：推理模型 conformity ratio 更低（中位差 −0.20）、正常脑 V12Gy 更低、对标准化物理师指令的响应更好、不可解析输出更少（25 vs 122）；与临床计划相比 PTV 覆盖等无显著差异。
- **为什么值得读**: 「后训练推理能力」在真实 TPS 优化任务中对通用模型的干净对照证据——agent 医疗落地中「推理型 vs 通用型」选型的实证参考。
- **链接**: https://www.nature.com/articles/s41598-026-73885-x

### 15. 🔥🔥 CASE: From Given to Gathered Evidence — Agentic Learning for Longitudinal Medical Reasoning
- **作者**: Minye Shao, Chaohui Yu, Yixuan Wu, Fan Wang, Ling Shao, Yang Long
- **来源**: arXiv（2026-09-30）· DOI: 10.48550/arxiv.2609.39566
- **摘要要点**: 传统医学 benchmark 评估「给定证据上的推理」，而非跨病历与纵向影像「主动寻证」的能力。提出 CASE：角色分工的寻证 clinical agents + tool-use harness + 面向紧凑 VLM 的 agentic 后训练框架；基于 UK Biobank 构建纵向多模态 benchmark（50,401 问题、4,739 参与者，基线+随访多序列 MRI，agent 自主选择就诊时点、器官、模态、切片与专科工具）。SFT 迁移 14,734 条前沿模型交互轨迹后做 agentic RL，配合特权 on-policy 自蒸馏与 rubric 式 LLM 反馈。Qwen3-VL-8B agent 在匹配评测条件下答案准确率相对 GPT-5.4 提升 >16%、相对 Claude Opus 4.8 提升 >10%。
- **为什么值得读**: 「寻证 agent」概念 + 纵向多模态 RL 后训练的完整配方；小模型经 agentic RL 超过前沿通用模型是强信号。
- **链接**: https://arxiv.org/pdf/2609.39566

## 🌐 跨界发现（Direction-X 与延伸信号）

### 🔥🔥 @fUS: Agentic transcranial functional ultrasound imaging
- bioRxiv（2026-09-28）· DOI: 10.64898/2026.09.25.752961
- 把 agent 架构直接焊进科学仪器：128 通道 fUS 硬件 + 可执行实验技能 + 持久结构化记忆，文字/语音控制，无工程背景的神经科学学生 30 分钟内独立配置。**「测量-计算-实验推理一体化」的仪器 agent 范式**——对想做 lab-in-the-loop 自主实验的人是重要参照。（注：非蛋白/非基因组目录，属仪器 agent 交叉方向，收录为跨界发现。）

### 🔥 Synthetic Hospital: An Open, Verifiable, Physician-Validated Longitudinal EHR Benchmark
- arXiv（2026-09-24）· DOI: 10.48550/arxiv.2609.30027（Park, Chen, Dettmers）
- 全合成、事实锚定的纵向 EHR 基准：1,268 名纵向患者、5,602 次就诊，全部诊断/发现/时间关系锚定 ICD-10-CM/SNOMED CT/LOINC 且溯源到公开医学教育材料；模拟医院系统提供标准互操作 API 与角色权限。盲评中医生区分其与真实病历的正确率仅 53%（近随机）。最好模型重建纵向问题清单 severity-weighted F1 仅 0.73。**解决真实 EHR 不可分享且无真值的双重困境**——Direction B 评测方向的重要基建。

### 📎 IMicAP: an intelligent microbial application platform for knowledge-driven microbiome research
- Frontiers in Microbiology（2026-10-01）· DOI: 10.3389/fmicb.2026.1955928
- 整合 12 个微生物数据库 + 3,500 万篇文献的 AI 平台：知识查询、多跳推理知识图谱、专业 QA、基因组浏览器、零代码 16S 分析；用生物医学语言模型抽取 microbe-disease 与 microbe-小分子关系。微生物知识基础设施与 Direction B 的 KG-RAG 可直接对接。

### 📎 CARD:Epi – Contextualizing Antimicrobial Resistance Determinants Using Deep Learning Language Models
- bioRxiv（2026-08-14）· DOI: 10.64898/2026.08.14.744850（McArthur lab）
- 用 BioBERT 从 204,094 篇 AMR 文献中做实体识别（ARG、分类群、环境、地理）+ 关系抽取，大规模刻画 ARG 传播脉络并可视化传输模式。文献挖掘路线的 AMR 语境化，与测序路线互补。

### 📎 Octave: Scale-resolved Evaluation of Spatial Gene Expression Prediction from Histology
- bioRxiv（2026-10-01）· DOI: 10.64898/2026.09.25.754484
- 揭示空间转录组-组学预测评测的系统性缺陷：常用 PCC 不区分空间尺度，粗粒度组织结构即可拿高分（domain oracle 可达训练模型 PCC 的 82%）。提出按微米级空间频带过滤打分的 OCTAVE 评测，最细频带重排 57 个图像编码器中 261/1596 对比较。**「评测指标掩盖真实能力」主题在组学 AI 中的又一次出现**——与 Evo 2 perplexity 失效（今日 #11）形成跨领域呼应。
