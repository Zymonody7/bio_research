## A. mNGS + AI 病原检测

### A1. ViroBench: Benchmarking Nucleotide Foundation Models on Viral Genomics Tasks 🔥🔥
- **ID**: [arXiv:2605.25388](https://arxiv.org/abs/2605.25388)
- **日期**: 2026-05-27
- **核心贡献**: **首个全面、大规模病毒基因组学的核苷酸基础模型 (NFM) 基准**。评估 66 个 NFM，覆盖 18 个场景（12 分类 + 6 生成），包含 58,314 高质量病毒序列。
- **关键发现**：
  - NFM 在**属级别分布外 (genus-disjoint) 和时间漂移 (temporal shift)** 下性能急剧下降 → 脆弱的外推能力
  - 生成任务揭示**统计似然与生物功能有效性解耦**，存在潜在生物安全风险
  - **预训练数据的物种多样性远超参数规模的重要性**：轻量级 baseline 获得 67.5% 性能增益
- **代码**: [github.com/QIANJINYDX/ViroBench](https://github.com/QIANJINYDX/ViroBench)
- **评价**: 填补病毒基因组学 NFM 系统评估的关键空白，对 mNGS 病原检测方法选型有直接指导意义。

### A2. GPAS: Online AI System for Rapid Pathogen Identification and LLM-Based Interpretation 🔥🔥
- **ID**: medrxiv:2026.02.18.26346517
- **日期**: 2026-02-18
- **核心贡献**: 整合三个创新的在线病原检测系统：① 非冗余高质量微生物基因组数据库 GenoDB；② 动态文库比对算法减少假阳性/假阴性；③ **LLM 驱动的病原解读 Agent**，自动将 mNGS 物种鉴定结果转化为临床可读报告。
- **评价**: LLM Agent 直接应用于 mNGS 临床报告生成的首批实践，代表了"检测→解读→报告"全链条自动化的方向。

## B. 临床 Agent + RAG / 知识图谱

### B1. MedAction: Towards Active Multi-turn Clinical Diagnostic LLMs 🔥🔥
- **ID**: [arXiv:2605.07305](https://arxiv.org/abs/2605.07305)
- **日期**: 2026-05-13
- **核心贡献**: 将诊断重新定义为**多轮主动诊断**（而非静态单轮），LLM 需在部分信息下逐步开检查、解读结果、更新鉴别诊断。构建 **MedAction-32K** 数据集（32,681 条轨迹，2,896 个 PMC 病例），提出两个 KG 锚定质量过滤指标 (DTC + RAC)。
- **关键发现**：当前医学 LLM 三大系统故障：无根据的开检查、不可靠的诊断更新、多轮一致性退化。根因：训练数据教会模型"思考"而非"行动"。
- **性能**: 8B 模型微调后在 MedR-Bench 和 MedAction-300-Hard 上达开源 SOTA。
- **评价**: 将临床 Agent 从"静态问答"推向"动态交互决策"，方法论和数据均可直接复用。

### B2. MedCoRAG: Interpretable Hepatology Diagnosis via Hybrid Evidence Retrieval and Multispecialty Consensus 🔥
- **ID**: [arXiv:2603.05129](https://arxiv.org/abs/2603.05129)
- **日期**: 2026-03-07
- **核心贡献**: 将 UMLS KG 路径与临床指南联合检索+剪枝，构建患者特异性证据包；Router Agent 根据病例复杂度动态调度专科 Agent，迭代推理并触发定向重检索；Generalist Agent 综合所有 deliberation 产出可追溯的共识诊断。
- **性能**: 在 MIMIC-IV 肝病病例上超越现有方法和闭源模型。
- **评价**: "动态专家调度 + 多源证据融合"的模式对 Agent + KG 临床决策系统具有通用参考价值。

### B3. LLM-as-a-Judge in Healthcare: A Scoping Analysis 📎
- **ID**: [arXiv:2605.25273](https://arxiv.org/abs/2605.25273)
- **日期**: 2026-05-27
- **核心贡献**: PRISMA 引导的系统性综述，纳入 134 篇研究。编码临床场景、Judge 配置、技术方法与验证设计。
- **关键发现**: OpenAI 模型是最常用的 Judge；Prompt Engineering 几乎出现在所有研究中；LLM Judge 常显示与专家判断的中到高度对齐，但可靠性因任务差异显著。
- **评价**: 方法参考——为 Agent 系统的自动评估模块设计提供技术选型依据。

## C. RLHF 医疗对齐与安全

### C1. Do No Harm? Hallucination and Actor-Level Abuse in Web-Deployed Medical LLMs 🔥🔥
- **ID**: [arXiv:2605.20591](https://arxiv.org/abs/2605.20591)
- **日期**: 2026-05-24
- **核心贡献**: **首次大规模审计 Web 部署的医疗 LLM 生态系统**。评估 OpenAI GPT Store 上 6,233 个 MedGPT（分层抽样 1,500 个）和 10 个开源医疗 LLM。
- **关键发现**：
  - 25-30% MedGPT 事实准确性低；底部和中层模型风险最高
  - 33.6-54.3% 违反运营阈值；57.06% 的 Action-enabled 模型缺乏隐私声明
  - 开源模型比 MedGPT 更稳定但准确率低
  - 平台信任指标与安全性**无相关性**；49.8% 模型违反运营政策
- **数据集**: 已发布 HAA-MedGPT 数据集
- **评价**: 对医疗 AI 部署安全治理的警钟——幻觉检测不能只看模型层，需到部署层进行完整性审计。

## D. 蛋白质语言模型

### D1. Conditional Antibody Sequence Generation with Germline-Absorbing Discrete Diffusion 🔥🔥
- **ID**: [arXiv:2605.06720](https://arxiv.org/abs/2605.06720)
- **日期**: 2026-05-13
- **核心贡献**: 提出 **Germline Absorbing Diffusion**——以胚系序列（而非 [MASK]）为离散扩散的吸收态，从根本上消除 PLM 对胚系序列的记忆偏差。允许任何现成分类器引导的条件生成（无需梯度）。
- **关键结果**:
  - 非胚系残基预测准确率从 26% → **46%**，接近理论上限 (53.8%)
  - 在临床抗体 Emibetuzumab 的亲和力优化中，生成设计的 Boltz-2 预测结合分数平均**提升 48%**
- **评价**: PLM + 扩散模型的巧妙结合，特别适合抗体设计中的体细胞突变建模。胚系吸收态的设计思想可推广到其他序列设计任务。

### D2. CHASE: Repurposing Protein Language Models for Latent Flow-Based Fitness Optimization 🔥
- **ID**: [arXiv:2602.02425](https://arxiv.org/abs/2602.02425)
- **日期**: 2026-02-04
- **核心贡献**: 将预训练 pLM 嵌入压缩到紧凑潜空间，训练条件流匹配模型 + Classifier-Free Guidance，实现**无需预测器引导**的高适应度蛋白变体直接生成。
- **性能**: AAV 和 GFP 基准上达 SOTA；数据增强 bootstrapping 进一步提升数据受限场景的性能。
- **评价**: 将流匹配引入蛋白适应度优化，避免了传统方法中昂贵的梯度采样，工程实用性高。

## E. 基因组基础模型

### E1. What Makes a Representation Good for Single-Cell Perturbation Prediction? 🔥🔥
- **ID**: [arXiv:2605.19343](https://arxiv.org/abs/2605.19343)
- **日期**: 2026-05-24
- **核心贡献**: 系统分析单细胞扰动预测中表征质量的决定因素。提出显式分离**扰动特异性信号**与**主导不变结构**的框架，通过因果表征学习恢复有效扰动信息。
- **关键洞察**: 基因表达被扰动不变信息主导，扰动特异性信号天然稀疏——现有方法（从因果表征学习到基础模型）均未充分解决此挑战。
- **评价**: 对设计下一代单细胞基因组基础模型有根本性指导意义——不应该只追求更大的模型，而需要更好的信号分离。

### E2. Probing 3D Chromatin Structure Awareness in Evo2 DNA Language Model 🔥
- **ID**: [arXiv:2604.07196](https://arxiv.org/abs/2604.07196)
- **日期**: 2026-04-10
- **核心贡献**: 系统探测 Evo2-7B（1M token 上下文，9.3 万亿核苷酸训练）是否隐式学习了 3D 染色质组织。通过似然扰动和序列生成实验评估 TAD 边界和 CTCF 环。
- **关键发现（负面结果）**:
  - Evo2 **未能区分**功能 3D 元素与匹配随机对照
  - 学会了局部 CTCF 语法，但**缺失高阶 3D 组织**
  - 需要**双向架构 + 细胞类型 + 3D 接触数据**，而非更长的上下文
- **评价**: 重要的"清醒剂"——更大 ≠ 更好，DNA 语言模型的设计需要根本性的架构创新来捕获 3D 调控逻辑。

## F. 多模态临床 Agent

### F1. ProtoMedAgent: Multimodal Clinical Interpretability via Privacy-Aware Agentic Workflows 🔥🔥
- **ID**: [arXiv:2605.14113](https://arxiv.org/abs/2605.14113)
- **日期**: 2026-05-20
- **核心贡献**: 将多模态临床报告生成形式化为**迭代零梯度测试时优化**，在严格神经符号瓶颈上操作。冻结原型骨干 → 隐私门控语义记忆（k-匿名 + ℓ-多样性）→ Scribe-Critic 反射循环，数学上排除不支持的主张。
- **关键结果**:
  - 4,160 患者队列: **91.2% Comparison Set Faithfulness**（vs. RAG 的 46.2%）
  - ℓ-多样性相变使成员推断风险**降低 9.8% 绝对值**
  - 解决了 RAG 的"检索谄媚"问题（LLM 编造相似性来事后合理化网络预测）
- **评价**: "神经符号瓶颈 + 反射 Agent"的范式在医疗可解释性上有很大潜力，隐私门控设计也符合 EU AI Act 的监管要求。

### F2. HiRRA: Region-Grounded Report Generation for 3D PET/CT with VietPET-RoI 🔥
- **ID**: [arXiv:2604.18145](https://arxiv.org/abs/2604.18145) (ACL 2026)
- **日期**: 2026-04-28
- **核心贡献**: 首个大规模 3D PET/CT 细粒度 RoI 标注数据集（600 样本，1,960 RoI）+ 层级区域感知 VLM 框架。GATv2 图网络建模 RoI 间空间/形态依赖，Qwen3-8B 生成报告。
- **性能**: +19.7% BLEU, +4.7% ROUGE-L, +45.8% 临床指标提升。
- **评价**: "先定位再描述"的放射科工作流模拟，RoI 级可解释性直接对应临床审核需求。

## 🧠 前沿洞察与头脑风暴（2026-05-28）

### 1. 从"静态检测"到"动态决策"——临床 Agent 范式的根本转变

本周最醒目的信号来自 **MedAction (B1)** 和 **MedCoRAG (B2)** 两篇工作：它们共同指向一个趋势——临床 AI 不再满足于在完整病历上做一次性诊断，而是在模拟真实的"信息不完整 → 逐步开检查 → 动态更新信念"的迭代决策过程。这与传统 MedQA 式 benchmark 形成鲜明对比。MedAction 提出的"thinking vs. acting"二分法尤为深刻：现有医学训练数据让模型学会从完整信息推理，但真正的临床决策是在不确定中行动。**交叉机会**：将 MedAction 的多轮决策范式与 MedCoRAG 的动态专家调度+证据检索结合，可能产生一种"一边检索知识、一边开检查、一边更新诊断"的端到端 Agent。

### 2. 隐私 × 可解释性的神经符号路径

**ProtoMedAgent (F1)** 提供了一个优雅的解决方案：将连续视觉推理压缩为离散语义记忆，并在隐私门控（k-匿名 + ℓ-多样性）下进行反射式报告生成。它的"神经符号瓶颈"概念值得关注——不是简单地让 LLM 看图说话，而是先用原型网络锁定"证据"，再约束 LLM 只能基于这些证据进行推理。这种"先取证、后推理"的范式天然抑制幻觉和检索谄媚。**白空间**：将这种神经符号瓶颈 + 隐私门控的设计推广到基因组学（如病原检测报告生成）和多组学数据解读中，可能催生一类"可审计的 AI 临床报告系统"。

### 3. 病毒基因组基础模型的两个关键瓶颈

**ViroBench (A1)** 明确指出 NFM 在病毒场景下的脆弱性：属级分布外泛化能力差，统计似然与生物功能有效性解耦。同时，**Evo2 3D 染色质探测 (E2)** 的负面结果提醒我们：在细菌上训练的 DNA LM 学不会真核生物的 3D 调控逻辑。**交叉信号**：两个方向共同指向"预训练数据生态位 (ecological niche)"的重要性——模型的泛化边界由其训练数据的进化范围决定。对 mNGS 病原检测而言，这意味着需要构建**病毒特化的基础模型**（而非通用 NFM），且在评估时必须使用严格的系统发育/时间分割。

### 4. 抗体的"个性化"生成——从胚系偏差到体细胞突变建模

**Germline-absorbing diffusion (D1)** 通过将胚系序列设为吸收态，巧妙地将 PLM 的学习目标从"记住胚系"扭转为"学习体细胞变异"。这不仅是抗体设计的进步，更暗示一种通用的序列设计范式：通过操控扩散过程的吸收态，可以显式控制模型应该"忽略"哪些先验。**白空间**：将胚系吸收扩散的思想与 CHASE (D2) 的潜空间流匹配结合，可能实现"可控的抗体适应度优化"——先消除胚系偏差，再在潜空间中进行适应度引导的生成。
